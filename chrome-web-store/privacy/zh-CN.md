# 智能页面滚动导航器 隐私政策

**最后更新日期**：2026 年 8 月 8 日

## 数据收集

在正常滚动功能运行期间，智能页面滚动导航器**不会**收集或传输您的浏览历史、访问网址或域名、页面标题、页面内容、搜索词、表单输入、滚动位置、已保存书签内容、账号信息或其他个人内容。唯一例外是您通过下文所述可选反馈表单主动提交的信息。

当前版本已下线匿名使用统计，不会收集、存储或传输任何使用统计数据。下文与统计相关的说明仅保留为 2.5.4 之前版本的历史处理记录。

开启后，扩展可能发送：

- 枚举化或区间化的扩展设置，例如按钮布局、尺寸区间、图标样式和阅读工具选项。
- 按 UTC 日期聚合的允许操作次数，例如顶部/底部按钮、快捷键、进度跳转、书签操作和目录操作。
- 按 UTC 日期聚合的插件及高级功能开启或关闭操作次数。
- 扩展版本和所选界面语言。

统计请求不包含网址、域名、页面标题、页面正文、书签数据、站点启用列表、精确自定义颜色、长期用户标识、广告标识或设备指纹。本扩展不会生成长期安装 ID 或用户 ID。

## 本地存储

本扩展程序使用 Chrome 内置存储 API（`chrome.storage.sync`）保存滚动速度、按钮位置、颜色、透明度和阅读工具等偏好设置，并通过 Google 基础架构在您登录 Chrome 的设备间同步。开启可选匿名统计后，只有上文说明的枚举化或区间化设置子集可能进入统计请求，不会发送精确自定义值。

当您选择使用相关功能时，本扩展程序也可能使用 `chrome.storage.local` 保存按站点启用状态和滚动位置书签。滚动位置书签包含页面 URL、大约滚动进度、页面标题和相关滚动容器元数据，用于后续提示您从该位置继续阅读。这些数据只保留在您的浏览器中，不会传输给扩展程序开发者或任何第三方。

当您启用智能段落跳转时，本扩展程序可能读取当前页面中可见的标题，用于在当前页面内存中生成页面目录。该目录及其中的标题文本和页面结构不会写入 Chrome 存储，也不会传输给扩展程序开发者或任何第三方。

匿名统计的同意状态、最近最多 7 个 UTC 日的待发送聚合计数和临时重试批次保存在 `chrome.storage.local`。关闭统计后，扩展会立即停止新增采集、删除待发送统计数据、停止上传调度并撤销可选统计权限。服务端此前收到的聚合统计会按下述保留期限到期删除。

## 主机权限

本扩展程序请求广泛的主机权限（`<all_urls>`），仅用于在网页中注入浮动滚动按钮。此权限是实现核心功能所必需的。扩展程序**不会**读取、拦截、收集、存储或传输您访问的任何网页内容。

统计端点权限和 `alarms` 定时调度权限均为可选权限。只有您开启匿名使用统计时，Chrome 才会请求这些权限，并仅用于向以下地址发送有大小限制的聚合统计批次：

`https://page-scroll-master-analytics.kscje-apps.workers.dev/v1/events`

## 统计处理与保留期限

统计端点由扩展开发者通过 Cloudflare Workers 和 Cloudflare D1 基础设施运营。本扩展不使用第三方统计 SDK、广告网络、追踪像素、Cookie、远程脚本或数据经纪服务。

服务端接收批次后会立即转换为按日聚合计数，不保存逐次操作事件。仅用于失败重试去重的随机批次 ID 最多保留 30 天，按日聚合统计最多保留 13 个月。

Cloudflare 可能依据其基础设施政策处理提供和保护服务所需的常规网络元数据，包括 IP 地址和请求头。扩展不会在统计请求中加入页面网址、来源页面、自定义用户代理数据或长期标识，开发者也不会使用网络元数据识别用户或建立用户画像。

匿名统计仅用于评估功能使用情况、设置分布、默认值和产品优先级，不会出售、用于广告或提供给他人进行画像。

## 建议与反馈提交

设置页提供可选的建议与反馈表单。只有您点击提交后，扩展才会发送反馈类型、反馈正文、扩展版本和所选界面语言。联系方式和最多 3 张 JPEG、PNG 或 WebP 图片仅在您主动提供时发送。表单不会读取当前页面 URL 或浏览器语言。反馈内容不会写入扩展 storage。

卸载扩展后，浏览器可能打开开发者运营的自愿卸载调研页面。页面打开本身不会提交卸载原因。只有您点击提交后，页面才会发送所选原因、可选补充说明、可选联系方式、扩展版本和所选界面语言。卸载调研不会收集访问网址、页面内容、书签、站点状态、设置明细或统计同意状态。

反馈端点由开发者通过 Cloudflare Workers 和 Cloudflare D1 运营，并通过 Resend 将内容和图片作为邮件转发到开发者邮箱。服务端使用经加盐哈希的网络地址进行小时级限流，不保存明文 IP；仅保存请求 ID、反馈类型、图片数量、卸载原因枚举、是否包含可选字段、发送结果和时间等不含正文的日志，最多保留 30 天。反馈正文、卸载调研补充说明、联系方式和图片不写入 D1。Cloudflare 和 Resend 可能依据各自政策处理提供和保护服务所需的数据。

反馈域名权限为可选权限，仅在您点击提交时请求，并在本次提交结束后撤销：

`https://page-scroll-master-feedback.kscje-apps.workers.dev/v1/feedback`

卸载调研页面使用：

`https://page-scroll-master-feedback.kscje-apps.workers.dev/uninstall`

## Chrome Web Store Limited Use

本扩展对通过 Chrome API 获得的信息的使用遵守 [Chrome Web Store User Data Policy](https://developer.chrome.com/docs/webstore/program-policies/limited-use)，包括 Limited Use 要求。数据只用于提供或改进扩展的单一用途，不会转移或用于个性化广告、信用决策，也不会出售给数据经纪商。

## 儿童隐私

本扩展程序不会有意收集任何人的个人信息，包括 13 岁以下的儿童。

## 本政策变更

如果对本隐私政策进行任何更改，将在更新版本的扩展程序和本政策页面上予以反映。
