# 智慧頁面捲動導覽器 隱私權政策

**最後更新日期**：2026 年 7 月 5 日

## 資料收集

在一般捲動功能運作期間，智慧頁面捲動導覽器**不會**收集或傳輸您的瀏覽紀錄、造訪網址或網域、頁面標題、頁面內容、搜尋詞、表單輸入、捲動位置、書籤內容或帳號資訊。唯一例外是您透過下方選用回饋表單主動提交的資料。

本擴充功能包含可選的匿名使用統計。新使用者和現有使用者預設均為關閉，只有您在設定頁主動開啟「傳送匿名使用統計」後，才會收集並傳輸資料。

啟用後，擴充功能可能傳送：

- 列舉化或區間化的擴充功能設定，例如按鈕版面、尺寸區間、圖示樣式和閱讀工具選項。
- 依 UTC 日期彙總的允許操作次數，例如頂部/底部按鈕、快速鍵、進度跳轉、書籤操作和目錄操作。
- 依 UTC 日期彙總的擴充功能及進階功能啟用或停用次數。
- 擴充功能版本和所選介面語言。

統計請求不包含網址、網域、頁面標題、頁面文字、書籤資料、網站啟用清單、精確自訂顏色、永久使用者識別碼、廣告識別碼或裝置指紋。本擴充功能不會建立長期安裝 ID 或使用者 ID。

## 本機儲存空間

本擴充功能使用 Chrome 內建儲存 API（`chrome.storage.sync`）儲存捲動速度、按鈕位置、顏色、透明度及閱讀工具等偏好設定，並透過 Google 基礎架構在您登入 Chrome 的裝置間同步。啟用可選匿名統計後，只有上述列舉化或區間化設定子集可能包含在統計請求中，不會傳送精確自訂值。

當您使用相關功能時，本擴充功能也可能使用 `chrome.storage.local` 儲存各網站的啟用狀態和捲動位置書籤。捲動位置書籤包含頁面 URL、大約捲動進度、頁面標題及相關捲動容器中繼資料，以便日後提示您從該位置繼續閱讀。這些資料只保留在您的瀏覽器中，不會傳送給擴充功能開發者或任何第三方。

啟用智慧段落跳轉時，本擴充功能可能讀取目前頁面上可見的標題，在目前頁面的記憶體中建立導覽目錄。該目錄、標題文字和頁面結構不會寫入 Chrome 儲存空間，也不會傳送給擴充功能開發者或任何第三方。

匿名統計同意狀態、最多最近 7 個 UTC 日的待傳送彙總計數和暫時重試批次會儲存在 `chrome.storage.local`。關閉統計後，擴充功能會立即停止新增收集、刪除待傳送統計資料、停止上傳排程並撤銷可選統計權限。伺服器先前收到的彙總統計會依下述保留期限到期刪除。

## 主機權限

本擴充功能要求廣泛的主機權限（`<all_urls>`），僅用於在網頁中注入浮動捲動按鈕。此權限是核心功能所必需。本擴充功能**不會**讀取、攔截、收集、儲存或傳輸您造訪的網頁內容。

統計端點權限和 `alarms` 排程權限均為可選權限。只有當您啟用匿名使用統計時，Chrome 才會要求這些權限，且僅用於向以下位址傳送有大小限制的彙總統計批次：

`https://page-scroll-master-analytics.kscje-apps.workers.dev/v1/events`

## 統計處理與保留期限

統計端點由擴充功能開發者透過 Cloudflare Workers 和 Cloudflare D1 基礎架構營運。本擴充功能不使用第三方統計 SDK、廣告網路、追蹤像素、Cookie、遠端指令碼或資料仲介服務。

伺服器接受批次後會立即轉換為每日彙總計數，不儲存個別操作事件。僅用於重試去重的隨機批次 ID 最多保留 30 天，每日彙總統計最多保留 13 個月。

Cloudflare 可能依其基礎架構政策處理提供和保護服務所需的一般網路中繼資料，包括 IP 位址和請求標頭。擴充功能不會在統計請求中加入頁面 URL、來源頁面、自訂使用者代理程式資料或永久識別碼，開發者也不會使用網路中繼資料識別使用者或建立個人檔案。

匿名統計僅用於評估功能使用情況、設定分布、預設值和產品優先順序，不會出售、用於廣告或提供給他人進行使用者分析。

## 建議與回饋提交

設定頁的選用回饋表單只會在您按下提交後傳送資料。提交內容包含回饋類型、正文、擴充功能版本和介面語言。聯絡方式及最多 3 張 JPEG、PNG 或 WebP 圖片只會在您主動提供時傳送。表單不會讀取目前頁面 URL 或瀏覽器語言。內容不會寫入擴充功能儲存空間。

解除安裝擴充功能後，瀏覽器可能開啟由開發者營運的自願解除安裝調研頁面。頁面開啟本身不會提交解除安裝原因。只有您按下提交後，才會傳送所選原因、選填補充說明、選填聯絡方式、擴充功能版本和所選介面語言。解除安裝調研不會收集造訪網址、頁面內容、書籤、網站狀態、設定明細或統計同意狀態。

服務由開發者透過 Cloudflare Workers 和 D1 營運，並使用 Resend 將郵件轉寄到開發者信箱。每小時限流只使用網路位址的加鹽雜湊，不儲存明文 IP。伺服器僅保留不含正文的日誌，最多 30 天，例如請求 ID、回饋類型、圖片數量、解除安裝原因枚舉、是否包含選填欄位、傳送結果與時間；正文、解除安裝調研補充說明、聯絡方式和圖片不寫入 D1。選用主機權限只在提交時請求，完成後撤銷。

## Chrome 線上應用程式商店有限使用規定

本擴充功能對透過 Chrome API 取得資訊的使用遵守 [Chrome Web Store User Data Policy](https://developer.chrome.com/docs/webstore/program-policies/limited-use)，包括 Limited Use 要求。資料僅用於提供或改善擴充功能的單一用途，不會轉移或用於個人化廣告、信用決策，也不會出售給資料仲介商。

## 兒童隱私權

本擴充功能不會故意收集任何人的個人資訊，包括 13 歲以下兒童。
