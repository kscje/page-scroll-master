# Smart Scroll Navigator 개인정보처리방침

**최종 업데이트**: 2026년 7월 5일

## 데이터 수집

일반 스크롤 기능을 사용하는 동안 Smart Scroll Navigator는 방문 기록, URL 또는 도메인, 페이지 제목과 콘텐츠, 검색어, 양식 입력, 스크롤 위치, 북마크 내용 또는 계정 정보를 **수집하거나 전송하지 않습니다**. 유일한 예외는 아래 선택형 피드백 양식으로 사용자가 명시적으로 제출하는 정보입니다.

확장 프로그램에는 선택적 익명 사용 통계 기능이 포함되어 있습니다. 신규 및 기존 사용자 모두 기본적으로 비활성화되어 있으며, 옵션 페이지에서 **익명 사용 통계 보내기**를 명시적으로 활성화한 경우에만 데이터를 수집하고 전송합니다.

활성화하면 다음 정보를 전송할 수 있습니다.

- 버튼 배치, 크기 범위, 아이콘 스타일, 읽기 도구 옵션과 같이 열거형 또는 구간화된 설정.
- 위/아래 버튼, 키보드 명령, 진행률 이동, 북마크 및 목차 작업과 같은 허용된 기능의 UTC 일별 집계 횟수.
- 확장 프로그램 및 고급 기능 활성화 또는 비활성화 작업의 UTC 일별 집계 횟수.
- 확장 프로그램 버전과 선택한 인터페이스 언어.

통계 요청에는 URL, 도메인, 페이지 제목, 페이지 본문, 북마크 데이터, 사이트 활성화 목록, 정확한 사용자 지정 색상, 영구 사용자 식별자, 광고 식별자 또는 기기 지문이 포함되지 않습니다. 확장 프로그램은 장기 설치 ID 또는 사용자 ID를 생성하지 않습니다.

## 로컬 저장소

확장 프로그램은 Chrome의 기본 저장소 API(`chrome.storage.sync`)를 사용하여 스크롤 속도, 버튼 위치, 색상, 투명도 및 읽기 도구 설정 등의 환경설정을 저장합니다. 이 데이터는 Google 인프라를 통해 Chrome에 로그인한 기기 간에 동기화됩니다. 선택적 통계를 활성화한 경우에도 위에서 설명한 열거형 또는 구간화된 설정 일부만 요청에 포함될 수 있으며 정확한 사용자 지정 값은 전송되지 않습니다.

관련 기능을 사용할 때 `chrome.storage.local`에 사이트별 활성화 상태와 스크롤 위치 북마크를 저장할 수 있습니다. 북마크에는 나중에 해당 위치에서 다시 시작할 수 있도록 페이지 URL, 대략적인 진행률, 페이지 제목 및 스크롤 컨테이너 관련 메타데이터가 포함됩니다. 이 데이터는 브라우저에만 남으며 개발자나 제3자에게 전송되지 않습니다.

스마트 섹션 탐색을 활성화하면 현재 페이지에 표시되는 제목을 읽어 메모리에 페이지 목차를 만들 수 있습니다. 목차, 제목 텍스트 및 페이지 구조는 Chrome 저장소에 저장되지 않으며 개발자나 제3자에게 전송되지 않습니다.

통계 동의 상태, 최대 최근 7 UTC 일의 전송 대기 집계 횟수 및 임시 재시도 배치는 `chrome.storage.local`에 저장됩니다. 통계를 끄면 새 데이터 수집을 즉시 중단하고, 대기 중인 데이터를 삭제하며, 업로드 일정을 중지하고 선택적 권한을 철회합니다. 서버가 이전에 받은 집계 통계는 아래 보존 기간에 따라 만료됩니다.

## 호스트 권한

확장 프로그램은 웹페이지에 플로팅 스크롤 버튼을 삽입하기 위한 목적으로만 광범위한 호스트 권한(`<all_urls>`)을 요청합니다. 이 권한은 핵심 기능에 필요합니다. 방문한 웹페이지의 콘텐츠를 **읽거나, 가로채거나, 수집하거나, 저장하거나, 전송하지 않습니다**.

통계 엔드포인트 권한과 `alarms` 예약 권한은 선택 사항입니다. 익명 사용 통계를 활성화한 경우에만 Chrome에서 요청하며, 크기가 제한된 집계 배치를 다음 주소로 보내는 용도로만 사용합니다.

`https://page-scroll-master-analytics.kscje-apps.workers.dev/v1/events`

## 통계 처리 및 보존

통계 엔드포인트는 확장 프로그램 개발자가 Cloudflare Workers와 Cloudflare D1 인프라를 사용하여 운영합니다. 제3자 통계 SDK, 광고 네트워크, 추적 픽셀, 쿠키, 원격 스크립트 또는 데이터 브로커를 사용하지 않습니다.

수신된 배치는 즉시 일별 집계 카운터로 변환되며 개별 작업 이벤트는 저장되지 않습니다. 재시도 중 중복 제거에만 사용하는 무작위 배치 ID는 최대 30일, 일별 집계 통계는 최대 13개월 동안 보존됩니다.

Cloudflare는 자체 인프라 정책에 따라 서비스를 제공하고 보호하는 데 필요한 IP 주소와 요청 헤더 등의 일반적인 네트워크 메타데이터를 처리할 수 있습니다. 확장 프로그램은 페이지 URL, 리퍼러, 사용자 지정 사용자 에이전트 데이터 또는 영구 식별자를 통계 요청에 추가하지 않으며, 개발자도 네트워크 메타데이터를 사용자 식별이나 프로파일링에 사용하지 않습니다.

통계 데이터는 기능 사용 현황, 설정 분포, 기본값 및 제품 우선순위를 평가하는 용도로만 사용됩니다. 판매하거나 광고에 사용하거나 프로파일링을 위해 공유하지 않습니다.

## 제안 및 피드백

선택형 피드백 양식은 사용자가 제출할 때만 데이터를 전송합니다. 유형, 내용, 확장 프로그램 버전, 인터페이스 언어가 포함됩니다. 연락처와 최대 3개의 JPEG, PNG 또는 WebP 이미지는 사용자가 제공한 경우에만 전송됩니다. 양식은 현재 페이지 URL이나 브라우저 언어를 수집하지 않습니다. 내용은 확장 프로그램 저장소에 저장되지 않습니다.

제거 후 브라우저가 개발자가 운영하는 자발적 제거 설문 페이지를 열 수 있습니다. 페이지를 여는 것만으로 제거 이유가 전송되지는 않습니다. 설문을 제출한 경우에만 선택한 이유, 선택 설명, 선택 연락처, 확장 프로그램 버전, 인터페이스 언어가 전송될 수 있습니다. 설문은 방문 URL, 페이지 내용, 북마크, 사이트 상태, 설정 세부 정보 또는 통계 동의 상태를 수집하지 않습니다.

서비스는 Cloudflare Workers와 D1을 사용하고 Resend로 개발자 이메일에 전달합니다. 시간당 제한에는 네트워크 주소의 솔트 해시만 사용하며 일반 IP는 저장하지 않습니다. 내용이 없는 로그만 최대 30일 보존합니다. 로그에는 요청 ID, 피드백 유형, 이미지 수, 제거 이유 enum, 선택 항목 포함 여부, 전달 결과와 시간이 포함될 수 있습니다. 본문, 제거 설문 설명, 연락처, 이미지는 D1에 저장하지 않습니다. 선택형 호스트 권한은 제출할 때 요청하고 완료 후 철회합니다.

## Chrome 웹 스토어 제한적 사용

Chrome API에서 받은 정보의 사용은 제한적 사용 요건을 포함한 [Chrome Web Store User Data Policy](https://developer.chrome.com/docs/webstore/program-policies/limited-use)를 준수합니다. 데이터는 확장 프로그램의 단일 목적을 제공하거나 개선하기 위해서만 사용되며 개인 맞춤 광고, 신용 결정 또는 데이터 브로커 판매를 위해 이전되거나 사용되지 않습니다.
