# スマートスクロールナビ プライバシーポリシー

**最終更新日**：2026 年 7 月 5 日

## データ収集

通常のスクロール機能の利用中、スマートスクロールナビは閲覧履歴、URL、ドメイン、ページタイトルや内容、検索語、フォーム入力、スクロール位置、ブックマーク内容、アカウント情報を**収集または送信しません**。唯一の例外は、下記の任意フォームからユーザーが明示的に送信する情報です。

本拡張機能には、任意の匿名利用統計があります。新規および既存ユーザーの初期設定では無効です。設定ページで「匿名の利用統計を送信」を明示的に有効にした場合にのみ、データを収集して送信します。

有効にした場合、次の情報を送信することがあります。

- ボタン配置、サイズ範囲、アイコンスタイル、読書ツールの選択肢など、列挙または範囲化された設定。
- 上下ボタン、キーボードコマンド、進捗ジャンプ、ブックマーク操作、目次操作など、許可された操作の UTC 日単位の集計回数。
- 拡張機能および高度な機能の有効化・無効化操作の UTC 日単位の集計回数。
- 拡張機能のバージョンと選択したインターフェース言語。

統計リクエストには、URL、ドメイン、ページタイトル、ページ本文、ブックマークデータ、サイト有効化リスト、正確なカスタムカラー、永続的なユーザー識別子、広告識別子、デバイスフィンガープリントは含まれません。本拡張機能は長期的なインストール ID やユーザー ID を作成しません。

## ローカルストレージ

本拡張機能は Chrome の組み込みストレージ API（`chrome.storage.sync`）を使用し、スクロール速度、ボタン位置、色、透明度、読書ツールなどの設定を保存します。これらは Google のインフラストラクチャを通じて、Chrome にログインしているデバイス間で同期されます。任意の統計を有効にした場合も、上記の列挙または範囲化された設定の一部のみが送信対象となり、正確なカスタム値は送信されません。

関連機能を使用する場合、`chrome.storage.local` にサイトごとの有効状態とスクロール位置ブックマークを保存することがあります。ブックマークには、後でその位置から再開できるよう、ページ URL、おおよその進捗、ページタイトル、スクロールコンテナに関するメタデータが含まれます。これらはブラウザ内にのみ保存され、開発者や第三者には送信されません。

スマートセクション移動を有効にすると、現在のページに表示されている見出しを読み取り、メモリ内にページ目次を作成することがあります。目次、見出しテキスト、ページ構造は Chrome ストレージに保存されず、開発者や第三者にも送信されません。

統計への同意状態、最大 7 UTC 日分の未送信集計回数、一時的な再試行バッチは `chrome.storage.local` に保存されます。統計を無効にすると、新しい収集を直ちに停止し、未送信データを削除し、送信スケジュールを停止して任意権限を取り消します。サーバーが以前受信した集計統計は、以下の保持期間に従って削除されます。

## ホスト権限

本拡張機能は、Web ページにフローティングスクロールボタンを挿入する目的に限り、広範なホスト権限（`<all_urls>`）を要求します。この権限は中核機能に必要です。アクセスした Web ページの内容を読み取り、傍受、収集、保存、送信することは**ありません**。

統計エンドポイント権限と `alarms` スケジュール権限は任意です。匿名利用統計を有効にした場合にのみ Chrome が要求し、サイズ制限付きの集計バッチを次の宛先へ送信する目的だけに使用します。

`https://page-scroll-master-analytics.kscje-apps.workers.dev/v1/events`

## 統計の処理と保持期間

統計エンドポイントは、拡張機能の開発者が Cloudflare Workers と Cloudflare D1 を使用して運用しています。第三者の統計 SDK、広告ネットワーク、トラッキングピクセル、Cookie、リモートスクリプト、データブローカーは使用しません。

受信したバッチは直ちに日単位の集計カウンターへ変換され、個別の操作イベントは保存されません。再試行時の重複排除だけに使用するランダムなバッチ ID は最大 30 日間、日単位の集計統計は最大 13 か月間保持されます。

Cloudflare は、インフラストラクチャポリシーに従い、サービスの提供と保護に必要な IP アドレスやリクエストヘッダーなどの通常のネットワークメタデータを処理する場合があります。本拡張機能はページ URL、リファラー、独自のユーザーエージェントデータ、永続的な識別子を統計リクエストに追加せず、開発者もネットワークメタデータをユーザー識別やプロファイリングに使用しません。

統計データは、機能利用状況、設定分布、初期値、製品の優先順位を評価する目的だけに使用されます。販売、広告利用、プロファイリング目的の共有は行いません。

## 提案・フィードバック

任意のフォームは、送信操作を行った場合だけデータを送ります。種類、本文、拡張機能のバージョン、表示言語が含まれます。連絡先と最大3枚の JPEG、PNG、WebP 画像は、ユーザーが指定した場合だけ送信されます。フォームは現在のページ URL やブラウザー言語を収集しません。内容は拡張機能のストレージに保存されません。

アンインストール後、ブラウザーが開発者運営の任意アンケートページを開く場合があります。ページを開いただけではアンインストール理由は送信されません。アンケートを送信した場合のみ、選択した理由、任意の補足説明、任意の連絡先、拡張機能のバージョン、表示言語が送信されます。アンケートは閲覧 URL、ページ内容、ブックマーク、サイト状態、設定詳細、統計同意状態を収集しません。

サービスは Cloudflare Workers と D1 で運用し、Resend で開発者へメール転送します。時間単位の制限にはネットワークアドレスのソルト付きハッシュだけを使用し、平文の IP は保存しません。本文を含まないログだけを最大30日保持します。ログにはリクエスト ID、フィードバック種別、画像数、アンインストール理由の列挙値、任意項目の有無、配信結果、時刻が含まれます。本文、アンインストールアンケートの補足説明、連絡先、画像は D1 に保存しません。任意のホスト権限は送信時に要求し、完了後に取り消します。

## Chrome ウェブストアの限定使用

Chrome API から取得した情報の使用は、Limited Use 要件を含む [Chrome Web Store User Data Policy](https://developer.chrome.com/docs/webstore/program-policies/limited-use) に準拠します。データは拡張機能の単一目的を提供または改善するためだけに使用し、パーソナライズ広告、信用判断、データブローカーへの販売のために移転または使用しません。

## 子どものプライバシー

本拡張機能は、13 歳未満の子どもを含め、個人情報を意図的に収集しません。

## ポリシーの変更

本プライバシーポリシーを変更する場合は、更新された拡張機能と本ページに反映します。
