## English

### Name

Smart Scroll Navigator – Top, Bottom & Progress

### Short Description

Long-page reading assistant: top/bottom jumps, auto scroll, progress, sections, saved positions, and Notion/Wiki support.

### Long Description

Smart Scroll Navigator is a lightweight Chrome page scrolling assistant built for long articles, online documents, Notion, wikis, knowledge bases, tutorials, and long dashboard pages.

It helps you jump to the top, scroll to the bottom, read with auto scroll, track page progress, navigate by page outline, and save reading positions without repeatedly dragging the scrollbar.

Main features:

- One-click top and bottom scrolling
- Previous-screen and next-screen navigation
- Auto scroll with speed settings and smart pause rules
- Page progress bar with click-to-jump support
- Scroll-position bookmarks for saving and restoring your place
- Smart section navigation generated from page headings
- Real scroll-container detection for Notion, wikis, and many SPA document pages
- Per-site controls for the extension and advanced tools
- Custom button position, size, color, opacity, icon, and style
- 13 interface languages

Useful for reading long articles, technical documentation, online courses, papers, product docs, forum threads, Notion pages, wikis, knowledge bases, and admin pages.

Privacy friendly:

Smart Scroll Navigator does not collect browsing history, visited URLs, page content, page titles, bookmark content, or personal identity data. Scroll positions and site states stay in local browser storage. Anonymous analytics is off by default and only sends aggregate data after explicit consent.

If you need a scroll-to-top button, scroll-to-bottom tool, auto-scroll extension, reading progress bar, long-page navigator, page outline, scroll bookmark, or Notion/Wiki reading assistant, Smart Scroll Navigator brings these tools together in one lightweight extension.

- Переход к началу или концу страницы одним нажатием
- Переход на предыдущий или следующий экран
- Автопрокрутка с настройкой скорости и умной паузой
- Индикатор прогресса страницы с переходом по клику
- Закладки позиции прокрутки для сохранения и восстановления места чтения
- Умная навигация по разделам на основе заголовков страницы
- Определение реального контейнера прокрутки для Notion, Wiki и многих SPA-документов
- Управление расширением и инструментами отдельно для каждого сайта
- Настройка положения, размера, цвета, прозрачности, значка и стиля кнопок
- Интерфейс на 13 языках

Подходит для длинных статей, технической документации, онлайн-курсов, исследований, описаний продуктов, форумов, страниц Notion, Wiki и баз знаний.

Конфиденциальность:

Smart Scroll Navigator не собирает историю браузера, посещенные URL, содержимое страниц, заголовки, содержимое закладок или персональные данные. Позиции прокрутки и состояния сайтов хранятся локально в браузере. Анонимная статистика выключена по умолчанию и отправляет только агрегированные данные после согласия.

Если вам нужна кнопка наверх, переход вниз, автопрокрутка, индикатор чтения, навигация по длинным страницам, оглавление, закладка позиции или помощник для Notion/Wiki, Smart Scroll Navigator объединяет эти инструменты в одном легком расширении.

Smart Scroll Navigator adalah asisten gulir Chrome yang ringan untuk artikel panjang, dokumen online, Notion, Wiki, basis pengetahuan, tutorial, dan halaman dashboard panjang.

- Navigasi layar sebelumnya / berikutnya

- Bilah progres halaman dengan klik untuk lompat
- Bookmark posisi gulir untuk menyimpan dan memulihkan tempat baca
