# v2.1 Privacy-Friendly Usage Analytics 子模块规格

本文档定义 Page Scroll Master v2.1 的匿名使用统计子模块。v2.1 的整体产品范围以 `doc/v2.1-product-plan-zh.md` 为准；本子模块的目标是帮助开发者理解功能使用情况和设置偏好，同时继续保持插件的隐私友好定位。

## 版本目标

v2.1 聚焦三个问题：

- 用户如何配置核心选项和高级功能。
- 页面进度条等高级模块的真实启用情况。
- 顶部、底部、进度跳转等日常操作的使用频率。

统计结果仅用于产品改进、默认值评估、功能优先级判断和问题排查。

## 非目标

以下能力不纳入 v2.1：

- 不追踪用户访问过的网址、域名、页面标题、页面内容或搜索词。
- 不记录单个网页的滚动深度、阅读时长、停留时长或热力图。
- 不构建跨站用户画像。
- 不接入广告、再营销、数据出售或第三方数据共享。
- 不在用户未同意时上传统计数据。
- 不加载远程托管 JavaScript SDK。
- 不用统计数据触发个性化广告或商业画像。

## 合规与隐私原则

v2.1 必须遵循以下原则：

- 默认关闭：新安装和升级用户默认不发送统计。
- 明确同意：设置页提供独立开关，用户主动开启后才上传。
- 可随时关闭：关闭后立即停止采集和上传，并清理本地待发送队列。
- 数据最小化：只上传功能事件和设置枚举值，不上传页面上下文。
- 匿名聚合：统计报表只看整体趋势，不查看单个用户历史路径。
- 透明披露：更新隐私政策、Chrome Web Store 隐私实践和设置页说明。
- 安全传输：只允许 HTTPS 端点。
- 无远程代码：统计客户端代码必须随扩展打包发布。

## 用户可见设置

设置页建议新增在“建议&反馈”或单独“隐私与统计”区域。

默认：

```js
analytics: {
  enabled: false
}
```

推荐文案：

```text
发送匿名使用统计
帮助改进功能优先级。仅发送功能开关、设置选项和按钮点击次数；不会收集访问网址、页面标题、页面内容或个人信息。
```

关闭行为：

- 不创建网络请求。
- 不记录新的事件。
- 删除本地 `analyticsQueue`。
- 保留 `analytics.enabled = false` 设置。

开启行为：

- 从开启后的行为开始统计。
- 不回传开启前的历史行为。
- 首次开启后发送一次匿名设置快照。

## 设置结构

使用 `chrome.storage.sync` 保存用户是否同意：

```js
settings: {
  analytics: {
    enabled: false
  }
}
```

使用 `chrome.storage.local` 保存待发送队列和临时批次状态：

```js
analyticsQueue: [
  {
    eventName: 'scroll_button_click',
    eventDate: '2026-06-03',
    payload: {
      direction: 'top',
      trigger: 'floatingButton'
    },
    createdAt: 1780492800000
  }
]
```

不要使用 `chrome.storage.sync` 保存事件队列，避免跨设备同步行为事件。

## 允许采集的数据

### 设置快照

事件名：

```text
settings_snapshot
```

触发时机：

- 用户开启匿名统计后立即发送一次。
- 用户保存设置后发送一次。
- 每天最多发送一次自动快照。

允许字段：

```js
{
  locale,
  extensionVersion,
  browserMajorVersion,
  buttonPosition,
  buttonSizeBucket,
  buttonSpacingBucket,
  edgeDistanceBucket,
  opacityBucket,
  iconSet,
  iconColorMode,
  progressBarEnabled,
  progressBarMode,
  progressBarHorizontalPosition,
  progressBarShowPercentage,
  progressBarShowRemainingTime,
  readingPositionEnabled,
  outlineNavigationEnabled
}
```

字段规则：

- 数值设置优先上传区间，不上传精确值。
- 颜色设置只上传模式，不上传自定义色值。
- 不上传站点启停列表。
- 不上传任何 URL、hostname、title、referrer。

### 点击计数

事件名：

```text
scroll_action_count
```

推荐本地聚合后上传，不逐次上传：

```js
{
  eventDate: '2026-06-03',
  topClicks: 12,
  bottomClicks: 9,
  progressJumpClicks: 3,
  returnPositionClicks: 1,
  popupTopClicks: 0,
  popupBottomClicks: 0,
  keyboardTopCommands: 2,
  keyboardBottomCommands: 1
}
```

规则：

- 按自然日聚合。
- 不包含发生在哪个网站或页面。
- 不包含滚动前后的位置。
- 不包含页面高度、阅读进度、阅读时间。

### 功能启用变化

事件名：

```text
feature_toggle_change
```

允许字段：

```js
{
  feature: 'progressBar',
  enabled: true,
  source: 'options'
}
```

规则：

- 只记录功能名和开关结果。
- 不记录具体网页上下文。

### 错误与兼容性事件

v2.1 可选采集低风险错误计数：

```js
{
  eventName: 'extension_error_count',
  eventDate: '2026-06-03',
  payload: {
    code: 'scroll_container_not_found',
    count: 4
  }
}
```

规则：

- 只允许预定义错误码。
- 不上传异常堆栈、页面 URL、DOM 选择器、页面文本。
- 如果错误码无法脱敏，则不要上传。

## 禁止采集的数据

v2.1 明确禁止上传：

- URL、origin、hostname、path、query、hash。
- 页面标题、meta 信息、正文文本、选中文本。
- DOM 结构、CSS 选择器、截图、网页缩略图。
- 用户输入内容、表单内容、账号信息。
- IP 以外的网络层标识；服务端也不得将 IP 用于画像。
- 设备指纹、长期跨站标识、广告 ID。
- 精确滚动位置、单页阅读进度、页面停留时长。
- 站点启停列表或按站点统计结果。

## 匿名标识策略

v2.1 推荐不生成长期用户 ID。

如后续确实需要估算去重活跃安装量，应优先采用服务端聚合窗口，而不是客户端永久 ID。若必须使用客户端标识，必须满足：

- 仅在用户开启统计后生成。
- 随机生成，不含设备、账号或浏览器特征。
- 至少每 90 天轮换一次。
- 用户关闭统计时立即删除。
- 隐私政策明确披露。

v2.1 首版不建议引入该标识。

## 上传策略

建议由 background service worker 统一发送：

- content script 只负责上报允许的本地事件。
- background 检查 `analytics.enabled` 后写入本地队列。
- 空闲或定时批量上传。
- 上传失败保留最多 7 天。
- 队列最多保留 200 条聚合事件，超过后丢弃旧事件。

端点建议：

```text
POST https://<analytics-domain>/v1/events
```

请求体示例：

```js
{
  schemaVersion: 1,
  extensionVersion: '2.1.0',
  locale: 'zh_CN',
  events: [
    {
      eventName: 'scroll_action_count',
      eventDate: '2026-06-03',
      payload: {
        topClicks: 12,
        bottomClicks: 9,
        progressJumpClicks: 3
      }
    }
  ]
}
```

请求要求：

- 只使用 HTTPS。
- 不带页面 URL、referrer 或自定义用户代理字段。
- 不使用第三方远程脚本。
- 服务端日志中的 IP 应设置短保留期，建议 7 到 30 天。

## 权限影响

v2.1 预计需要新增网络请求目标：

```json
{
  "host_permissions": [
    "https://<analytics-domain>/*"
  ]
}
```

如果仅使用 `fetch()` 请求固定 HTTPS 端点，应避免扩大到 `<all_urls>` 网络权限。

Chrome Web Store 发布前必须更新：

- `doc/privacy-policy.md`
- `doc/privacy-policy-zh.md`
- Chrome Web Store Data Usage / Privacy practices
- 商店描述中的隐私说明
- README 隐私说明

## 数据保留

推荐保留策略：

- 原始事件：最多 30 天。
- 日级聚合表：最多 13 个月。
- 服务端访问日志：7 到 30 天。
- 用户关闭统计后：客户端立即停止并清空队列；服务端历史聚合按统一保留策略过期。

## 报表口径

v2.1 初版只输出聚合报表：

- 已同意统计用户中的功能启用率。
- 已同意统计用户中的设置分布。
- 每日顶部/底部/进度跳转点击量。
- 高级功能开启后的互动变化。
- 版本升级前后设置变化。

注意：由于默认关闭，v2.1 的统计不能代表全部用户，只能代表主动同意匿名统计的用户。

## 验收标准

v2.1 完成必须满足：

- 默认无任何统计网络请求。
- 用户开启统计后才发送事件。
- 关闭统计后不再发送事件，并清理本地队列。
- 所有事件 payload 均不包含 URL、hostname、title、referrer、page text。
- 设置快照只包含枚举值或区间值。
- 点击统计按日聚合，不逐次上传浏览上下文。
- 隐私政策和 Chrome Web Store 隐私实践已更新。
- 测试覆盖同意开关、队列清理、payload 脱敏和发送失败重试。
