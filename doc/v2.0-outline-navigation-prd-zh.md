# v2.0 智能段落跳转产品需求文档

本文档定义 Page Scroll Master v2.0「智能段落跳转」的产品目标、功能边界、目录解析规则、交互行为、设置结构、动态页面适配和验收标准。

本文档是 v2.0 智能段落跳转的主要产品依据，优先级高于 `doc/advanced-features-development-guide-zh.md` 中的早期概要。实现方案可以在不改变本文档产品行为和验收结果的前提下调整。

## 版本结论

v2.0 聚焦长页面中的轻量目录导航，不新增常驻侧边栏，但提供独立于滚动位置书签的目录按钮。

核心定位：

- 使用独立「智能段落跳转」按钮，不与滚动位置书签入口合并。
- 默认关闭，不改变现有用户体验。
- 默认只解析当前主要滚动内容中的 `h1` 和 `h2`。
- 提供页面目录、上一段、下一段和当前章节高亮。
- 优先保证目录质量，不追求收录页面中的所有标题。
- 对 SPA 和动态内容采用可失效、可重新生成的目录快照。

## 用户问题

用户阅读长技术文档、教程、Wiki、知识库或长文章时，常见问题包括：

- 无法快速了解页面章节结构。
- 需要反复滚动才能找到目标章节。
- 在当前章节和相邻章节之间移动成本较高。
- 某些页面没有目录，或者原站目录在滚动后不可见。

本功能通过独立目录按钮提供轻量页面目录和相邻章节跳转，帮助用户在长页面中快速定位。

## 目标用户

- 经常阅读技术文档、教程、Wiki 和知识库的用户。
- 需要在长文章多个章节之间来回切换的用户。
- 使用飞书 Wiki、Notion、语雀、钉钉文档等 SPA 文档页面的用户。
- 已使用 Page Scroll Master 滚动位置书签或页面进度功能的用户。

## 非目标

以下能力不纳入 v2.0：

- 常驻侧边栏式目录。
- AI 摘要、章节总结或内容改写。
- 自动滚动或演示模式。
- 目录搜索、收藏、编辑或手动排序。
- 用户自定义 CSS 选择器或域名过滤规则。
- 复杂的广告和推荐区识别模型。
- 键盘快捷键跳转上一段或下一段。
- 跨页面目录、站点级目录或多页面知识图谱。
- v1.9.1 的书签匹配和恢复增强功能。
- v2.1 的匿名使用统计。

## v2.0 交付范围

v2.0 交付以下 9 项：

1. 智能段落跳转设置和默认配置。
2. 当前主要滚动内容中的标题解析。
3. 基础语义噪声过滤和标题质量过滤。
4. 智能段落跳转菜单包含固定动作区和目录滚动区。
5. 页面目录展示及点击跳转。
6. 上一段和下一段跳转。
7. 当前章节高亮。
8. SPA 路由变化和动态内容变化后的目录失效与重建。
9. 典型页面、动态页面和自定义滚动容器的质量验收。

## 产品原则

- 默认关闭，由用户主动启用。
- 不新增常驻目录面板。
- 不与滚动位置书签入口合并。
- 目录只在用户打开智能段落跳转菜单时展示。
- 标题过滤以减少误收为优先，允许少量低价值标题不被收录。
- 目录顺序必须遵循页面内容顺序。
- 页面变化后重新生成目录，不尝试长期持有失效的页面节点。
- 所有目录分析只在用户浏览器内完成，不上传页面标题或页面结构。

## 默认设置

v2.0 在现有 `advancedSettings` 中增加：

```js
outlineNavigation: {
  enabled: false,
  buttonPosition: 'pageBottom',
  buttonColorMode: 'followTopButton',
  buttonCustomColor: '#4A9EDD',
  sources: {
    h1: true,
    h2: true,
    h3: false,
    idBlocks: false
  },
  maxItems: 30,
  filterShortHeadings: true,
  highlightCurrentSection: true
}
```

字段说明：

- `outlineNavigation.enabled`：是否启用智能段落跳转，默认 `false`。
- `outlineNavigation.buttonPosition`：智能段落跳转按钮位置，默认 `pageBottom`。
- `outlineNavigation.buttonColorMode`：智能段落跳转按钮颜色模式，可选跟随顶部按钮、跟随底部按钮或自定义，默认 `followTopButton`。
- `outlineNavigation.buttonCustomColor`：自定义按钮颜色，默认 `#4A9EDD`。
- `sources.h1`：是否收录 `h1`，默认 `true`。
- `sources.h2`：是否收录 `h2`，默认 `true`。
- `sources.h3`：是否收录 `h3`，默认 `false`。
- `sources.idBlocks`：是否额外收录带 `id` 的非标题区块，默认 `false`。
- `maxItems`：目录每批加载的项目数，默认 `30`，允许范围 `10-50`；保留字段名以兼容已有设置。
- `filterShortHeadings`：是否过滤过短或低信息标题，默认 `true`。
- `highlightCurrentSection`：是否高亮当前章节，默认 `true`。

兼容规则：

- 旧用户没有 `outlineNavigation` 时自动补齐默认值。
- 旧版 `readingTools.features.outlineNavigation` 仅作为兼容迁移来源，新保存结构不再依赖 `readingTools`。
- 如果用户取消所有目录来源，保存时恢复为 `h1 + h2`，不允许有效来源为空。
- `idBlocks` 属于高级来源，开启时必须继续经过可见性、语义和文本质量过滤。

## 智能段落跳转菜单

### 前置改造

v2.0 的智能段落跳转菜单必须独立于滚动位置书签菜单，避免两个高级功能继续共享同一个入口。

菜单至少支持两类内容：

- 固定动作区。
- 可滚动目录区。

菜单项应由配置或构建函数生成，但本文档不限定具体代码抽象形式。

### 菜单结构

智能段落跳转开启时：

```text
┌────────────────────────┐
│ 上一段             [↑] │
│ 下一段             [↓] │
├────────────────────────┤
│ 页面目录                │
│ Introduction            │
│ Installation            │
│ Configuration           │
│ API Reference           │
└────────────────────────┘
```

规则：

- 固定动作区不随目录列表滚动。
- 目录区位于固定动作区下方，直接展示，不设置二次「页面目录」入口。
- 目录区最大高度为 `40vh`，超出后内部滚动。
- 菜单整体不得超出视口，应延续现有左右展开和边缘避让逻辑。
- 菜单打开时解析目录；有效缓存存在时可以直接复用。
- 点击目录项后执行平滑跳转并保持菜单打开，用户通过目录标题区的关闭按钮手动关闭。
- 点击菜单外部区域继续关闭菜单。
- H1、H2、H3 目录项按标题级别递增缩进，非标题区块不参与标题层级缩进。
- 首批目录项按 `maxItems` 加载，默认显示前 30 项；存在更多项目时提供“加载更多”，每次继续加载一批。

### 与滚动位置书签的组合

- 只启用滚动位置书签：只显示独立书签按钮和书签菜单。
- 只启用智能段落跳转：只显示独立目录按钮和目录菜单。
- 两者都启用：显示两个独立按钮，菜单内容互不混合。
- 两者都关闭：不显示书签按钮或目录按钮。

### 边界状态

- 当前已处于第一个目录项之前或第一个目录项：上一段按钮禁用。
- 当前已处于最后一个目录项：下一段按钮禁用。
- 禁用按钮使用灰色和不可点击状态，不额外显示 Toast。
- 未检测到有效标题时，目录区显示「未检测到可跳转标题」，上一段和下一段同时禁用。

## 标题解析范围

### 主解析范围

目录优先在当前主要滚动容器中解析，而不是无条件扫描整个 `document`。

规则：

1. 使用现有滚动容器检测能力确定当前主要滚动容器。
2. 如果滚动容器是页面根滚动元素，则优先按 `main`、`[role="main"]`、`article` 的顺序选择正文范围，均不存在时回退到 `body`。
3. 如果滚动容器是自定义内部容器，则只解析该容器的后代节点。
4. 目录跳转和当前章节计算必须使用同一个滚动容器。
5. 滚动容器发生变化时，现有目录快照立即失效。

### 默认来源

默认收录：

- `h1`
- `h2`

可选收录：

- `h3`
- 带 `id` 的非标题区块

`idBlocks` 开启时，不应把所有 `[id]` 节点直接作为目录项。候选节点必须具备可读文本，并通过后续全部过滤规则。

## 噪声和质量过滤

### 语义祖先过滤

候选标题位于以下祖先节点中时默认排除：

```text
nav
footer
aside
header
[role="banner"]
[role="navigation"]
[role="complementary"]
table / thead / tbody / tfoot / tr / th / td
figcaption
blockquote
cite
```

例外：

- 如果检测到的主要滚动容器本身就是上述元素，不因容器标签直接排除其全部内容。
- 位于 `li` 内的标题默认排除，避免书目、引文和卡片字段进入目录；如果标题与 `li` 之间存在独立的 `article`、`section` 或 `main` 内容区块，则允许保留。
- v2.0 不使用 `z-index` 数值作为硬过滤条件。

### 可见性过滤

排除：

- `display: none`。
- `visibility: hidden`。
- 没有布局尺寸且不在正常文档流中的标题。
- 已从 DOM 中移除的节点。

折叠组件中的标题只有在实际展开、可见时才进入目录。仅凭父容器撑起高度不能视为标题可见。

### 文本质量过滤

排除：

- 空文本或仅包含空白字符。
- 去除空白后少于 2 个有效字符的标题。
- 只包含标点、图标或序号的标题。
- 纯数字、ISBN、ISSN、OCLC、DOI、SSRN 等标识符。
- 与相邻候选项文本相同且位置非常接近的重复标题。

纯数字和标识符属于结构性低价值文本，即使用户关闭“自动过滤过短标题”也继续排除；该设置只放宽正常语言标题的长度要求。

标题文本处理：

- 合并连续空白。
- 去除首尾空白。
- 保留用户可见的原始语言和大小写。
- 显示时允许截断，但跳转目标不受显示截断影响。

### Shadow DOM

- 扩展自身 Shadow DOM 不属于宿主页面解析范围。
- 宿主页面 `closed` Shadow DOM 中的标题无法被普通 DOM 查询访问，不纳入 v2.0。
- 宿主页面开放的 Shadow DOM 不要求递归解析，后续版本可根据实际需求评估。

## 目录数据和生命周期

### 目录快照

每个目录项在当前快照生命周期内至少包含：

```js
{
  id,
  text,
  level,
  element,
  order
}
```

说明：

- `element` 可以在当前快照中用于跳转和位置计算。
- 不将 `element` 写入存储。
- 不使用 `{ text, tagName, domIndex }` 跨页面恢复旧目录项。
- 快照失效后整批重新解析，不对旧元素引用做补救匹配。

### 快照失效条件

以下情况使目录快照失效：

- 页面 URL 发生变化。
- 检测到主要滚动容器变化。
- 目录来源设置变化。
- 目录相关过滤设置变化。
- 主要内容区域发生有效的子树增删。
- 快照中的目标元素已断开 DOM。

### SPA 和动态页面

v2.0 必须支持不触发 `DOMContentLoaded` 的 SPA 路由变化。

建议行为：

- 监听 `popstate`。
- 识别 `pushState` 和 `replaceState` 导致的 URL 变化。
- 复用现有 `MutationObserver`，对主要内容区域的子树变化进行防抖处理。
- URL 变化时立即关闭菜单、清空高亮状态并标记目录失效。
- DOM 变化时只标记目录失效；菜单关闭期间不必反复完整解析。
- 用户再次打开菜单时生成最新目录。
- 菜单打开期间发生有效变化时，防抖后刷新目录。

建议防抖时间为 `300-500ms`，具体值由实现验证决定。

## 目录排序和数量限制

### 排序

- 目录项始终按照 DOM 内容顺序排列。
- 不按标题层级重新分组。
- 明确来自 `h1/h2/h3` 的目录项按标题级别递增缩进，非标题区块不参与层级缩进。
- `h1/h2` 不因优先级而打乱原始顺序。

### 数量限制

- 默认首批显示 `30` 项。
- 用户可设置每批加载 `10-50` 项。
- 首批按 DOM 顺序显示前 `maxItems` 项。
- 存在更多项目时在目录底部显示“加载更多”和剩余数量，每次继续加载一批。
- 加载更多不重新扫描页面，复用当前完整目录快照。

该限制用于控制菜单可用性和运行成本，不代表后续标题不存在。

## 跳转行为

### 点击目录项

- 使用现有 `smoothScrollTo()` 执行平滑滚动。
- 跳转目标应以标题进入阅读区域为准，不要求标题紧贴视口最顶端。
- 建议在目标标题上方保留 `8-24px` 的阅读间距。
- 根滚动页面和自定义滚动容器必须使用各自正确的坐标体系。
- 目标节点失效时取消跳转，并在下次打开菜单时重新解析，不跳转到猜测位置。

### 上一段

- 以当前滚动容器中的阅读锚点为基准。
- 跳转到当前章节之前的上一有效目录项。
- 如果用户位于当前标题顶部附近，上一段应前往真正的上一标题，而不是重复跳转当前标题。

### 下一段

- 跳转到当前阅读锚点之后的第一个有效目录项。
- 如果已处于最后一个目录项，按钮禁用。

## 当前章节高亮

### 产品语义

当前章节代表「用户当前正在阅读的区域」，不等同于「最近进入视口的标题」。

判断规则：

- 使用视口或滚动容器可视区域顶部约 `30%` 处作为阅读锚点。
- 高亮阅读锚点之前最后一个有效标题。
- 如果阅读锚点仍位于第一个标题之前，不高亮或高亮第一个标题，由实际体验测试确定，但同一版本内必须保持一致。

### 更新方式

- 根滚动页面监听页面滚动。
- 自定义滚动容器监听该容器滚动。
- 使用 `requestAnimationFrame` 或约 `100ms` 节流更新。
- 实现应避免每次滚动都对全部目录项进行无界布局测量。
- 可以使用预计算位置、二分查找或邻近项检查；具体实现不属于产品强制要求。
- `IntersectionObserver` 可以作为辅助，但不得把「进入视口」直接等同于当前章节。

### 菜单表现

- 当前章节目录项使用清晰但克制的高亮样式。
- 菜单打开时，应将当前章节项滚动到目录区可见范围内。
- 关闭 `highlightCurrentSection` 后不显示高亮，但上一段和下一段仍可用。

## 设置页

在「高级功能」中新增独立「智能段落跳转」模块：

```text
[ ] 启用智能段落跳转

按钮位置：
( ) 页面顶部
(•) 页面底部
( ) 上/下按钮之间

按钮颜色：
(•) 跟随顶部按钮
( ) 跟随底部按钮
( ) 自定义颜色

目录来源：
[x] H1
[x] H2
[ ] H3
[ ] 带 id 的区块

每批加载目录项：
[ 30 ]

[x] 自动过滤过短标题
[x] 当前章节高亮
```

交互规则：

- 关闭智能段落跳转时隐藏或禁用其子设置。
- `maxItems` 输入范围为 `10-50`，超出时显示校验提示；该兼容字段表示每批加载数量。
- 用户取消全部来源时，自动恢复 `H1 + H2` 并显示简短说明。
- 设置保存后，已打开页面中的目录缓存失效并响应新设置。
- 设置页预览只需展示独立目录按钮是否出现，不需要模拟真实页面目录。

## 无障碍和键盘行为

- 智能段落跳转按钮和菜单项必须可通过键盘聚焦。
- `Enter` 和 `Space` 可触发菜单动作。
- `Escape` 关闭菜单并将焦点返回智能段落跳转按钮。
- 菜单打开后焦点进入第一个可用动作。
- 禁用的上一段或下一段应暴露正确的禁用状态。
- 当前章节高亮不能只通过颜色表达，应同时使用 `aria-current` 或等效语义。
- 目录项文本应提供完整可访问名称，即使视觉上被截断。

## 性能要求

- 功能关闭时不运行标题解析和章节高亮逻辑。
- 菜单未打开且缓存有效时不重复解析目录。
- 动态 DOM 变化使用防抖，不对每个 mutation 立即扫描页面。
- 滚动高亮更新不得明显影响页面滚动流畅度。
- 单次解析只处理当前解析范围和已启用来源。
- 分批加载不能代替候选扫描优化，但应限制首次渲染规模。

## 隐私要求

- 标题文本、页面结构和目录快照只在当前页面内存中处理。
- 不将目录内容写入 `chrome.storage.local` 或 `chrome.storage.sync`。
- 不向远程服务发送页面标题、目录内容或当前章节。
- 设置项可以继续保存在 `chrome.storage.sync`。

## 异常和降级行为

- 无有效滚动容器：回退到页面根滚动元素。
- 无有效标题：显示空状态并禁用上一段、下一段。
- 页面标题动态移除：标记快照失效并在下一次需要时重建。
- 跳转目标失效：取消本次跳转，不猜测替代节点。
- 页面禁止平滑动画或用户启用减少动态效果：允许立即跳转。
- 菜单空间不足：限制目录区高度并内部滚动，不覆盖顶部/底部按钮。

## 质量验收场景

至少覆盖以下页面类型：

1. 标准文章：正文中有一个 `h1` 和多个 `h2`。
2. 多级文档：包含 `h1/h2/h3`。
3. 导航噪声页面：顶部导航、侧栏、页脚均包含标题节点。
4. 电商或门户页面：推荐区和广告区包含标题节点。
5. 自定义滚动容器页面。
6. SPA 路由切换页面。
7. 动态加载或折叠展开标题的页面。
8. 重复标题文本页面。
9. 超过 50 个有效标题的长文档。
10. 没有有效标题的页面。
11. 百科或出版物页面：章节标题下包含作者、期刊名、卷号、ISBN、OCLC、DOI、SSRN 等书目字段。

## 完成定义

v2.0 只有在以下条件满足时才算完成：

- 默认关闭，升级后不显示任何新增目录 UI。
- 开启后显示独立智能段落跳转按钮，不与滚动位置书签入口合并。
- 默认只解析当前主要滚动内容中的 `h1/h2`。
- 导航、页脚、侧栏等基础结构标题不会进入目录。
- 书目列表、引用、表格和标识符等结构性元数据不会进入目录。
- 目录项按正文 DOM 顺序展示。
- 点击目录项能在根页面和自定义滚动容器中正确跳转。
- 上一段和下一段按照当前阅读位置跳转，并在边界正确禁用。
- 当前章节高亮符合阅读锚点语义，不仅依赖标题是否进入视口。
- SPA 路由切换后旧目录不再可用，重新打开菜单可生成新目录。
- 动态内容变化后目录可以失效并重建。
- 目录项超过首批数量时明确显示“加载更多”和剩余数量。
- 菜单固定动作区和目录滚动区不会互相遮挡。
- 功能关闭时不运行额外的目录解析和滚动高亮监听。
- 页面标题和目录数据不写入存储、不发送到远程服务。
- 新增自动化测试覆盖核心解析、过滤、跳转、边界和 SPA 生命周期。
- 所有现有回归测试和构建脚本通过。

## 建议自动化测试

建议新增 `tests/test-outline-navigation.js`，至少覆盖：

- 默认设置关闭。
- 旧设置自动补齐。
- 默认只启用 `h1/h2`。
- 全部来源关闭时恢复 `h1/h2`。
- 解析范围限定在主要滚动容器。
- 排除 `nav/footer/aside/header` 和相关 ARIA role 后代。
- 排除隐藏、空文本、过短和相邻重复标题。
- 排除书目列表、表格、引用容器、纯数字和常见出版物标识符。
- 保持 DOM 顺序。
- `maxItems` 默认 30，范围限制为 10-50，并作为每批加载数量。
- 首批只渲染一批，加载更多后按 DOM 顺序追加下一批。
- 上一段和下一段边界。
- 当前章节阅读锚点计算。
- URL 变化使目录快照失效。
- DOM 变化使目录快照失效。
- 自定义滚动容器跳转坐标正确。
- 书签功能关闭时菜单不显示书签项。
- 目录功能关闭时菜单不显示目录相关项。
