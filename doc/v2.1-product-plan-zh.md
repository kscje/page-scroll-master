# v2.1 Product Experience & Privacy Update 产品规划

本文档定义 Page Scroll Master v2.1 的整体产品范围。v2.1 在 v2.0 长页面导航能力之上，补充站点级高级功能控制、新用户引导、版本更新记录和隐私友好的匿名使用统计。

匿名使用统计的详细边界见 `doc/v2.1-usage-analytics-spec-zh.md`，实施步骤见 `doc/v2.1-usage-analytics-implementation-plan-zh.md`。

## 版本目标

v2.1 聚焦四项能力：

1. 用户可直接在浏览器工具栏 Popup 中，按当前域名控制各高级功能是否启用。
2. 新用户首次成功安装扩展后自动打开设置页，完成首次认知和配置。
3. 在设置页“建议&反馈”模块内新增“更新记录”，简要展示各版本主要新功能和优化项。
4. 在用户主动同意后采集匿名聚合使用统计，用于评估功能优先级和默认值。

## 非目标

以下能力不纳入 v2.1：

- 不改变现有“整个扩展按站点启用/停用”的兼容语义。
- 不支持按完整 URL、路径、标签页或页面规则配置高级功能。
- 不为域名级高级功能设置增加云同步。
- 不在扩展升级、浏览器启动或普通重载时自动打开设置页。
- 不从远程服务加载更新记录。
- 不在用户未同意时上传匿名统计。
- 不提前实现 v3.0 的扩展内直接提交反馈服务。

## 功能一：按域名启用高级功能

### 产品目标

用户无需进入完整设置页，即可在当前网页对应的浏览器工具栏 Popup 中，控制各高级功能是否在当前域名生效。

该能力用于处理不同网站的兼容性和使用场景差异。例如，用户可以在文档网站启用页面进度条和智能段落跳转，但在其他网站仅保留顶部、底部基础按钮。

### Popup 交互

保留现有“在此网站启用扩展”总开关，并在其下新增“高级功能”区域。

建议结构：

```text
在此网站启用扩展                         [开]

高级功能
页面进度条                               [开]
滚动位置书签                             [关]
智能段落跳转                             [开]

[打开设置]
```

交互规则：

- Popup 根据当前活动标签页的 hostname 读取和保存设置。
- 只允许在内容脚本可运行且能获得有效 hostname 的普通网页上修改。
- `chrome://`、扩展页面、新标签页等不支持页面显示不可用状态，不写入空域名。
- 整个扩展的站点总开关关闭时，高级功能开关显示为不可用，但保留各自已保存状态。
- 高级功能全局开关关闭时，对应域名开关显示为不可用，并提示需先到设置页启用该功能。
- Popup 修改后应立即通知当前标签页刷新对应功能，不要求用户手动刷新页面。

### 生效规则

每个高级功能的最终状态由“全局设置”和“当前域名设置”共同决定：

```text
最终启用 = 整个扩展在当前站点启用
        AND 高级功能全局启用
        AND 当前域名未明确关闭该高级功能
```

兼容原则：

- 未保存域名级状态时，默认视为启用，不改变升级用户当前行为。
- 域名级设置只能关闭或恢复全局已启用的功能，不能绕过全局关闭状态。
- 站点总开关和高级功能域名开关互相独立，不能复用同一个布尔值。
- 新增高级功能时，未出现在旧域名记录中的功能默认启用。

### 存储建议

域名级高级功能状态属于站点数据，保存在 `chrome.storage.local`，不进入 `chrome.storage.sync`。

建议结构：

```js
advancedFeatureEnableStates: {
  'example.com': {
    progressBar: false,
    scrollBookmarks: true,
    outlineNavigation: false
  }
}
```

存储规则：

- 只保存用户明确修改过的域名和功能状态。
- 删除某域名记录后恢复“跟随全局设置”。
- 域名标准化规则应与现有 `enableStates` 保持一致。
- 不把域名级状态加入匿名统计快照或事件 payload。

### 设置页管理

现有站点状态管理模块应能够区分：

- 整个扩展在该站点是否启用。
- 各高级功能在该站点是否有覆盖设置。

v2.1 至少应提供清除单个域名高级功能覆盖和清除全部覆盖的能力，避免只能通过访问目标网站恢复默认状态。

### 验收标准

- Popup 可以按当前 hostname 修改每个已支持高级功能的域名级状态。
- 未设置过的域名继续沿用全局高级功能设置。
- 关闭站点总开关后不创建任何高级功能 DOM 或监听器。
- 修改域名级状态后当前页面立即更新，重复切换不产生重复 DOM 或监听器。
- 自定义滚动容器和 SPA 页面中的高级功能启停行为正确。
- 域名信息仅保存在本地，不进入匿名统计。

## 功能二：新安装后自动打开设置页

### 产品目标

让新用户在安装成功后立即看到功能说明、基础设置和高级功能入口，降低“安装后不知道如何配置”的问题。

### 触发规则

- 使用 `chrome.runtime.onInstalled` 监听安装事件。
- 仅当 `details.reason === 'install'` 时调用 `chrome.runtime.openOptionsPage()`。
- 扩展升级、Chrome 更新、浏览器启动、扩展重载和设置重置时均不自动打开。
- 自动打开失败不能影响扩展安装和基础滚动功能。

### 设置页首屏要求

自动打开后使用现有默认标签页，不强制用户开启任何高级功能或匿名统计。

首屏应让用户能够快速理解：

- 扩展的顶部、底部滚动核心功能。
- 如何打开浏览器工具栏 Popup。
- 高级功能默认状态及其设置入口。
- 匿名统计默认关闭，需要用户主动开启。

### 验收标准

- 全新安装后自动打开一次设置页。
- 从旧版本升级到 v2.1 不自动打开设置页。
- 浏览器重启和扩展 service worker 重启不重复打开。
- 自动打开行为不修改任何用户设置。

## 功能三：建议&反馈中的更新记录

### 产品目标

让用户在扩展内快速了解当前版本和历史版本的主要变化，提高新功能可发现性，并减少用户必须前往 README 或商店页面查看版本信息的成本。

### 信息架构

在设置页“建议&反馈”标签内新增独立“更新记录”卡片，与“关于插件”和联系方式并列。

建议结构：

```text
更新记录

v2.1.0
- 新增按域名控制高级功能
- 新用户安装后自动打开设置页
- 新增扩展内更新记录
- 新增可选匿名使用统计

v2.0.0
- 新增智能段落跳转和页面大纲导航
- 优化长页面章节识别和跳转体验
```

展示规则：

- 当前版本置顶，历史版本按版本号倒序排列。
- 默认展示每个版本 2 到 5 条用户可理解的主要新功能和优化项。
- 不展示提交记录、内部重构、测试调整等工程细节。
- 历史版本较多时默认只展开最近版本，其余版本可折叠查看。
- 版本号应与 `manifest.json` 一致。
- 文案应覆盖当前支持的所有 Options 语言。

### 数据与维护规则

- 更新记录随扩展包本地发布，不发送网络请求，不依赖远程 Markdown 或接口。
- `doc/CHANGELOG.md` 继续作为完整变更记录。
- 设置页更新记录是面向用户的简要摘要，不替代完整 Changelog。
- 每次版本发布时，同时更新 `manifest.json`、`README.md`、`doc/CHANGELOG.md` 和设置页更新记录。

### 验收标准

- “建议&反馈”内可以查看当前版本和主要历史版本摘要。
- 当前展示版本与 `manifest.json` 一致。
- 所有支持语言都有对应标题、版本摘要和交互文案。
- 更新记录在离线状态下可用，且不产生网络请求。
- 内容在窄窗口和长文本语言下仍可阅读。

## 功能四：隐私友好的匿名使用统计

### 产品目标

在用户主动同意后，采集不含页面上下文的匿名聚合事件，帮助评估核心设置分布、高级功能启用率和常用操作频率。

### 产品边界

- 默认关闭，新安装和升级用户均不发送统计。
- 不上传 URL、域名、页面标题、页面内容、站点启停列表或域名级高级功能状态。
- 关闭后立即停止采集和上传，并清理本地待发送队列。
- 详细事件、权限、保留期和验收规则以 `doc/v2.1-usage-analytics-spec-zh.md` 为准。

## 建议实施顺序

1. 新安装后自动打开设置页。
2. “建议&反馈”中的更新记录。
3. Popup 按域名控制高级功能及设置页覆盖管理。
4. 匿名使用统计、隐私披露和服务端上传。

前两项依赖少，可先完成产品体验闭环；域名级高级功能控制需要同时修改 Popup、内容脚本和本地存储；匿名统计需要先确认服务端、权限和隐私合规。

## v2.1 完成定义

v2.1 只有在以下条件满足时才算完成：

- 四项产品能力均按各自验收标准实现。
- 旧用户升级后现有站点启停和高级功能行为不发生意外变化。
- 新安装只自动打开一次设置页，不自动开启高级功能或匿名统计。
- 更新记录与发布版本一致，并完成全部支持语言覆盖。
- 域名级高级功能状态仅保存在本地，未进入匿名统计。
- 匿名统计默认关闭，代码行为、隐私政策和商店披露一致。
- 对应 Node 回归测试、真实扩展 Popup/设置页检查和浏览器 Network 检查通过。
