# v2.4 Store Rating Prompt 产品规划

本文档定义 Page Scroll Master v2.4 的首个规划范围：在用户已经实际使用插件后，通过工具栏 Popup 底部的轻量提示，邀请用户前往 Chrome Web Store 为插件评分；同时在设置页“关于插件”模块提供一个用户主动点击的常驻评分入口。

## 版本目标

v2.4 聚焦一项能力：

1. 增加应用商店评分入口：Popup 底部提供低打扰、可拒绝、可永久关闭的主动邀请；设置页“关于插件”模块提供常驻入口。

该能力的目标是提高真实满意用户的评分转化，同时保持中性文案、最小打扰和 Chrome Web Store 政策合规。

## 非目标

- 不在首次安装、首次打开 Popup 或页面加载时立即提示评分。
- 不使用系统通知、内容页浮层或会遮挡网页的弹窗。
- 不要求用户给五星，不提供评分奖励，不把评分作为解锁功能的条件。
- 不读取或发送当前页面 URL、页面标题、浏览内容或评分结果。
- 不新增远程请求、遥测字段、Chrome 权限或外部服务。
- 不把评分邀请状态同步到其他设备。
- 不把设置页常驻评分入口纳入 Popup 主动邀请的展示次数或冷却规则。

## 功能一：Popup 底部评分邀请

### 产品目标

当用户已经安装插件一段时间，并且累计多次主动打开 Popup 后，在 Popup 底部显示一个中性邀请卡片，引导用户前往 Chrome Web Store 评分。

该功能应满足：

- 只在用户主动打开 Popup 时出现。
- 只在当前主域名未关闭插件时出现。
- 提示区域位于 Popup 底部，不抢占顶部站点控制和高级功能开关。
- 用户可以选择前往评分、稍后再说或不再提示。
- 所有频控状态保存在本地，不进入同步设置。

### 入口与显示位置

评分邀请仅显示在 `popup.html` / `popup.js` 管理的工具栏弹窗中：

```text
Popup 主体
  当前网站总开关
  高级功能开关
  设置入口
  评分邀请卡片（满足条件时显示在底部）
```

不在以下位置显示：

- `content.js` 注入的页面浮动按钮区域。
- 浏览器系统通知。
- 新安装自动打开的设置页或快速开始引导。

设置页会提供独立的常驻评分入口，但不显示主动邀请卡片。

### 触发条件

所有条件必须同时满足才允许展示：

- 当前插件版本为 v2.4 或更高，并且当前版本尚未展示过评分邀请。
- 距离安装时间至少 7 天。
- 用户累计点击打开 Popup 超过 10 次。
- 当前用户整体评分邀请展示次数少于 2 次。
- 用户没有点击过“不再提示”。
- 用户没有点击过“去评分”。
- 用户没有处于“稍后再说”冷却期内。
- 当前主域名的插件总开关未关闭。

“累计点击打开 Popup 超过 10 次”按 Popup 页面初始化成功并完成当前标签页状态读取后计数。无法解析当前标签页或当前页面不支持扩展注入时，仍可计入 Popup 打开次数，但不展示评分邀请。

### 频控规则

- 用户点“稍后再说”后，至少 30 天不再提示。
- 用户点“不再提示”后，永久不再主动提示。
- 用户点“去评分”后，永久不再主动提示。
- 每个用户每个版本最多展示 1 次。
- 每个用户整体最多展示 2 次。
- 当前站点被停用时不提示，也不消耗当前版本展示次数。

展示次数只在邀请卡片实际渲染出来后累加。由于 Popup 生命周期短，渲染失败或条件不满足不能计入展示次数。

### 存储设计

评分邀请状态保存在 `chrome.storage.local`，不进入 `chrome.storage.sync`：

```js
ratingPromptState: {
  installedAt: 1710000000000,
  popupOpenCount: 11,
  totalShownCount: 1,
  shownVersions: {
    '2.4.0': true
  },
  dismissedUntil: 1713000000000,
  neverAsk: false,
  ratedClicked: false
}
```

字段说明：

- `installedAt`：首次记录评分邀请状态的时间。若用户从旧版本升级且缺少该字段，使用首次运行 v2.4 代码的时间作为起点，不追溯历史安装时间。
- `popupOpenCount`：本设备累计 Popup 打开次数。
- `totalShownCount`：本设备累计实际展示评分邀请次数。
- `shownVersions`：已展示过邀请的版本集合，用于保证每版本最多展示 1 次。
- `dismissedUntil`：用户选择“稍后再说”后的冷却截止时间。
- `neverAsk`：用户选择“不再提示”后的永久关闭标记。
- `ratedClicked`：用户点击“去评分”后的永久关闭标记。

兼容规则：

- 旧用户缺少 `ratingPromptState` 时，通过深合并补齐默认值。
- 存储损坏或字段类型异常时，回退到不展示，并在下次正常写入时修正结构。
- 不读取匿名统计 consent，不复用匿名统计队列，也不新增统计事件。

### 文案原则

文案必须保持中性、礼貌和可拒绝：

```text
如果这个插件帮到了你，欢迎在 Chrome Web Store 给我们评分。
```

按钮：

```text
去评分
稍后再说
不再提示
```

禁止使用以下表达：

- “请给五星好评”
- “评分后解锁”
- “支持我们就给满分”
- 任何诱导、奖励、威胁或暗示必须给高分的文案

### 跳转行为

用户点击“去评分”后：

1. 立即写入 `ratedClicked: true`。
2. 打开 Chrome Web Store 评分页面。
3. 关闭或隐藏当前 Popup 中的评分邀请。

建议将商店评分地址集中为常量：

```js
const STORE_REVIEW_URL = 'https://chromewebstore.google.com/detail/<extension-id>/reviews';
```

实现前应使用真实已发布扩展 ID 验证评分页面 URL。若 Chrome Web Store 当前页面结构无法稳定定位评分区，则跳转到商店详情页，并在文案中保持“前往商店页面”语义。

## 功能二：设置页关于插件常驻评分入口

### 产品目标

在设置页“建议&关于插件”标签下的“关于插件”模块内，新增一个常驻评分入口。该入口面向已经进入设置页的用户，由用户主动点击，不属于主动打扰。

### 入口位置

入口放在 `options.html` 现有 `about-card` 内，与版本号、作者和反馈联系方式相邻：

```text
建议&关于插件
  关于插件
    当前版本
    插件作者
    联系方式
    前往 Chrome Web Store 评分
```

展示规则：

- 始终显示，不受安装天数、Popup 打开次数、稍后再说、当前版本展示次数或整体展示次数影响。
- 当前主域名插件总开关关闭时仍显示，因为设置页入口是用户主动访问的全局入口，不是当前站点提示。
- 用户点击 Popup 的“不再提示”后，设置页常驻入口仍保留。
- 用户点击 Popup 或设置页的“去评分”后，设置页常驻入口仍保留，方便用户之后再次打开商店页面。

### 交互行为

用户点击设置页常驻入口后：

1. 直接打开 Chrome Web Store 评分页面。
2. 不改变 `ratingPromptState.neverAsk`。
3. 可以写入 `ratingPromptState.ratedClicked: true`，用于阻止后续 Popup 主动邀请。
4. 不增加 `totalShownCount`，不写入 `shownVersions`，不设置 `dismissedUntil`。

设置页入口应复用 Popup 的商店评分 URL 常量或同一 helper，避免两个入口跳转地址不一致。

### 与当前主域名状态的关系

评分邀请展示前必须读取当前主域名状态：

- 当前主域名插件总开关为关闭：不提示。
- 当前页面无法解析主域名或不支持扩展运行：不提示。
- 高级功能开关关闭不影响评分邀请，只看插件总开关。
- 评分邀请本身不改变任何主域名启停状态。

### 本地化范围

评分邀请属于 Popup 内嵌文案，必须覆盖：

- `popup.js` 的 Popup 翻译表。
- `popup.js` 的 `normalizeLanguage()` 已支持语言。
- 必要时补充 `_locales/*/messages.json` 中与商店页面或扩展说明相关的文案，但不要为了 Popup 内嵌文案重复维护 Chrome locale key。

设置页常驻入口属于 Options 内嵌文案，必须覆盖：

- `options.js` 的 Options 翻译表。
- `options.js` 的 `normalizeLanguage()` 已支持语言。
- `options.html` 中新增入口的 `data-i18n` key。

支持语言范围沿用 v2.3 的 13 种语言：

- 简体中文、繁体中文、英文、西班牙语、日语、德语、法语、葡萄牙语、韩语、意大利语、俄语、土耳其语、印度尼西亚语。

### 隐私与权限

- 不新增权限。
- 不新增外部请求。
- 不读取当前页面 URL、标题或内容。
- 不读取用户是否真的完成评分。
- 不发送评分邀请展示、点击或关闭数据到远程服务。
- 状态仅保存在 `chrome.storage.local`，用于本地频控。
- 设置页常驻入口只打开商店评分页，不读取页面内容，也不发送评分结果。

## 建议实施顺序

1. 在 `popup.js` 中建立评分邀请默认状态、深合并和频控判断 helper。
2. 在 Popup 初始化流程中记录打开次数，并在当前主域名状态读取完成后判断是否展示。
3. 在 `popup.html` 底部增加评分邀请容器，并在 `popup.js` 中渲染、隐藏和绑定按钮行为。
4. 在设置页“关于插件”模块增加常驻评分入口，并复用同一个商店评分跳转 helper。
5. 补齐 13 种 Popup 和 Options 文案，并检查 Popup 窄宽度和设置页卡片布局。
6. 添加回归测试，覆盖安装 7 天、Popup 打开次数、当前站点关闭、稍后再说、不再提示、去评分、每版本一次、整体两次，以及设置页常驻入口不消耗频控次数。
7. 更新 README、CHANGELOG 和必要的发布检查项。

## 验收标准

- 安装未满 7 天不展示。
- Popup 累计打开次数不超过 10 次不展示。
- 当前主域名插件总开关关闭时不展示。
- 满足条件时评分邀请只显示在 Popup 底部。
- 点击“稍后再说”后 30 天内不再展示。
- 点击“不再提示”后永久不再展示。
- 点击“去评分”后打开商店评分页，并永久不再展示。
- 同一版本最多展示 1 次。
- 同一用户整体最多展示 2 次。
- 设置页“关于插件”模块常驻显示评分入口。
- 设置页评分入口点击后直接打开商店评分页。
- 设置页评分入口不消耗 Popup 主动邀请的展示次数，也不受“稍后再说”冷却影响。
- 文案中性，不诱导五星评分，不提供奖励。
- 不新增权限、远程请求或隐私披露义务。
- 对应 Node 回归测试通过，`git diff --check` 通过。

## v2.4 完成定义

v2.4 只有在以下条件满足时才算完成：

- Popup 底部评分邀请按频控规则稳定展示和隐藏。
- 设置页“关于插件”模块提供常驻评分入口，且复用同一商店评分跳转地址。
- 旧用户升级后不会立即打扰，至少从 v2.4 首次记录时间起等待 7 天。
- 站点停用、稍后提醒、永久关闭、已点击评分和版本展示次数互不冲突。
- 所有 Popup 和 Options 语言文案完整，窄窗口或设置页卡片内不遮挡核心操作。
- 不新增 Chrome 权限、网络请求、远程统计或页面数据读取。
- 相关回归测试、真实 Chrome Popup 验收和发布资料检查通过。
