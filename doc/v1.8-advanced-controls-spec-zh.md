# v1.8 Advanced Controls 功能规格

本文档定义 Page Scroll Master v1.8 的产品行为、默认值、存储结构、UI 规则和验收标准。后续开发应以本文档作为 v1.8 的功能契约。

> 2026-06-10 后续版本修订：从 v2.1 起，页面进度条是否启用由 Popup 按当前主域名控制；设置页只保留显示样式、颜色、尺寸和交互参数。v1.8 的 `advancedSettings.progressBar.enabled` 仅作为旧版本兼容和迁移来源。

## 版本目标

v1.8 的目标是增加一组默认关闭的高级功能，让插件从“一键顶部/底部滚动”增强为“轻量页面滚动控制工具”，同时不改变现有用户的默认体验。

v1.8 包含四项功能：

- 可配置阅读进度条
- 按钮图标样式与颜色自定义
- 设置页网站启用状态管理
- 新增西班牙语和日语支持

## 非目标

以下功能不纳入 v1.8：

- 滚动位置书签和自动恢复
- 智能段落跳转和页面目录
- 自动滚动/演示模式
- 滚动热力图
- 页面 Mini-Map
- 用户真实上传自定义图标
- 进度条拖动 scrub

## 兼容性要求

### 默认体验不变

用户未开启高级功能时，网页内仍只显示当前两个浮动按钮：

```text
┌──────┐
│  ▲   │
└──────┘

┌──────┐
│  ▼   │
└──────┘
```

不得默认显示进度条、进度按钮、图标选择提示或其他高级控件。

### 旧设置兼容

升级到 v1.8 后，旧用户没有 `advancedSettings` 时必须使用默认值，不得报错，不得改变按钮样式。

### 现有行为兼容

以下行为必须保持：

- 点击顶部按钮滚动到顶部
- 点击底部按钮滚动到底部
- 快捷键继续有效
- Popup 按站点启用/禁用继续有效
- 设置页原有选项继续有效
- 全屏时按钮隐藏
- SPA 滚动容器检测继续有效

## 存储结构

### sync 存储

v1.8 新增 `advancedSettings`，存储在 `chrome.storage.sync`。

默认值：

```js
const DEFAULT_ADVANCED_SETTINGS = {
  progressBar: {
    enabled: false,
    mode: 'verticalButton',
    horizontalPosition: 'top',
    colorMode: 'followTopButton',
    customColor: '#4A9EDD',
    thickness: 3,
    verticalHeight: 72,
    clickToJump: true,
    showPercentage: false,
    showRemainingTime: false
  },
  iconCustomization: {
    enabled: false,
    iconSet: 'defaultArrow',
    iconColor: '#FFFFFF',
    customIcon: {
      enabled: false,
      topIconDataUrl: '',
      bottomIconDataUrl: ''
    }
  }
};
```

v1.8 不应在 `advancedSettings` 中实现 `readingPosition` 和 `outlineNavigation`，以免误导当前版本功能范围。长期路线图见 `doc/advanced-features-development-guide-zh.md`。

### local 存储

继续使用现有 `enableStates`，存储在 `chrome.storage.local`。

```js
{
  enableStates: {
    'example.com': false,
    'notion.so': true
  }
}
```

未出现在 `enableStates` 中的 hostname 视为启用。

## 功能一：可配置阅读进度条

### 旧版本开关

设置项：`advancedSettings.progressBar.enabled`

默认值：`false`

从 v2.1 起不再由设置页读写该字段；迁移完成后，页面进度条启用状态以主域名本地状态为准。

关闭时：

- 不创建横向进度条
- 不创建纵向进度按钮
- 不绑定额外滚动监听
- 不影响现有两个按钮布局

开启时，按 `mode` 显示对应 UI。

### 显示模式

#### 纵向进度按钮

设置项：`advancedSettings.progressBar.mode = 'verticalButton'`

进度按钮显示在上/下按钮之间，是按钮组中的第三个按钮。

```text
┌──────┐
│  ▲   │
└──────┘

┌──────┐
│ 37%  │
│ ███  │
│ ███  │
│ ░░░  │
└──────┘

┌──────┐
│  ▼   │
└──────┘
```

视觉规则：

- 宽度等于 `buttonSettings.buttonSize`
- 高度为 `advancedSettings.progressBar.verticalHeight`
- 最小高度 40px，最大高度 240px
- 形状跟随 `buttonSettings.buttonShape`
- 间距使用 `buttonSettings.buttonSpacing`
- 外层透明度跟随 `buttonSettings.opacity`
- 默认颜色按 `colorMode` 解析
- 内部文字颜色使用 `advancedSettings.iconCustomization.iconColor`，未开启图标自定义时为 `#FFFFFF`

交互规则：

- 点击进度按钮时，按点击高度跳转到对应进度
- 顶部代表 100%，底部代表 0%
- `clickToJump = false` 时禁用点击跳转，但仍显示进度
- 悬停可显示 `title`，格式如 `37%`

#### 横向页面边缘进度条

设置项：`advancedSettings.progressBar.mode = 'horizontalBar'`

横向进度条固定在页面顶部或底部。

```text
████████████░░░░░░░░░░░░░░░░ 37%
```

位置：

- `advancedSettings.progressBar.horizontalPosition = 'top'`
- `advancedSettings.progressBar.horizontalPosition = 'bottom'`

视觉规则：

- `position: fixed`
- 宽度覆盖视口
- 高度为 `thickness`
- `z-index` 应高于普通网页内容，但不高于扩展按钮组
- 默认颜色按 `colorMode` 解析
- 不改变网页布局，不给 body 添加 padding

交互规则：

- 点击横向位置时，按点击横坐标跳转到对应进度
- 左侧代表 0%，右侧代表 100%
- `clickToJump = false` 时禁用点击跳转，但仍显示进度
- `showPercentage = true` 时可在右端显示百分比或用悬停提示显示百分比

### 颜色规则

设置项：`advancedSettings.progressBar.colorMode`

可选值：

- `followTopButton`
- `followBottomButton`
- `custom`

解析规则：

```text
followTopButton    使用 buttonSettings.topButtonColor
followBottomButton 使用 buttonSettings.bottomButtonColor
custom             使用 advancedSettings.progressBar.customColor
```

颜色必须经过 HEX 校验。无效时回退到 `#4A9EDD`。

### 进度计算

必须复用现有滚动容器工具函数：

- `resolveScrollContainer()`
- `getScrollTop(container)`
- `getElementScrollRange(container)`
- `setScrollTop(container, top)`

进度计算：

```js
progress = range <= 0 ? 0 : clamp(getScrollTop(container) / range, 0, 1)
```

页面不可滚动时显示 0%，但控件仍可显示。点击跳转不应报错。

### 点击跳转

v1.8 必须抽取通用滚动函数：

```js
smoothScrollTo(container, targetTop)
```

并让以下逻辑复用它：

- `scrollToTop()`
- `scrollToBottom()`
- 纵向进度按钮点击跳转
- 横向进度条点击跳转

跳转速度必须继续受现有 `scrollSpeed` 控制。

### 滚动监听

进度条只在开启时绑定滚动监听。

监听要求：

- 使用 `requestAnimationFrame` 节流
- 绑定到当前真实滚动容器
- 根滚动场景可绑定 `window`
- 容器变化时解绑旧容器，绑定新容器
- 移除进度条时清理监听

### SPA 兼容

当 SPA 页面导致滚动容器变化时，进度条必须重新绑定容器并刷新。

现有 `detectAndUpdateScrollContainer()` 或容器更新入口应通知进度模块。

### 全屏和站点禁用

全屏时：

- 按钮隐藏
- 纵向进度按钮隐藏
- 横向进度条隐藏

站点禁用时：

- 移除按钮
- 移除进度条
- 清理进度条监听

### 剩余阅读时间

设置项：`advancedSettings.progressBar.showRemainingTime`

默认值：`false`

v1.8 可以实现，但不是必须优先项。若实现：

- 英文/西班牙语按 250 words/min
- 中文/日语按 500 chars/min
- 只显示近似值
- 不得阻塞页面初始化

## 功能二：按钮图标样式与颜色自定义

### 开关

设置项：`advancedSettings.iconCustomization.enabled`

默认值：`false`

关闭时，保持当前白色上/下箭头。

### 图标组

设置项：`advancedSettings.iconCustomization.iconSet`

v1.8 至少提供：

- `defaultArrow`
- `triangle`
- `chevron`
- `minimalArrow`
- `doubleArrow`

所有图标使用内联 SVG，不使用字体符号。

### 图标颜色

设置项：`advancedSettings.iconCustomization.iconColor`

默认值：`#FFFFFF`

颜色必须校验为 HEX。无效时回退到 `#FFFFFF`。

图标 SVG 应使用 `currentColor`，按钮通过 CSS `color` 控制颜色。

### 自定义上传预留

v1.8 只预留数据结构，不实现上传：

```js
customIcon: {
  enabled: false,
  topIconDataUrl: '',
  bottomIconDataUrl: ''
}
```

设置页可以显示“上传自定义图标 Coming soon”，但不要提供可点击上传入口，避免用户误解。

## 功能三：设置页网站启用状态管理

### 目标

在设置页集中管理 Popup 已保存的站点启用/禁用状态。

### 列表显示

仅展示用户手动保存过的站点，即 `enableStates` 中存在的 hostname。

每行包含：

- hostname
- 当前状态：启用/禁用
- 切换控件
- 删除按钮

### 搜索

支持按 hostname 子字符串过滤。

### 添加规则

用户可输入：

- `example.com`
- `https://example.com/page`
- `http://sub.example.com/path`

系统应解析为 hostname。

非 http/https URL 或空 hostname 应提示错误，不保存。

### 批量操作

必须提供：

- 恢复全部启用：清空 `enableStates`
- 清除已关闭站点：删除所有值为 `false` 的记录

### 同步行为

设置页修改 `enableStates` 后：

- Popup 应通过 `chrome.storage.onChanged` 同步状态
- 内容脚本应通过现有 local storage 监听更新页面按钮显示

## 功能四：新增语言支持

### 新增语言

v1.8 新增：

- 西班牙语：`es-ES`
- 日语：`ja-JP`

### Chrome locale 文件

新增：

```text
_locales/es/messages.json
_locales/ja/messages.json
```

### JS 翻译对象

必须同步新增：

- `options.js` 中 `translations['es-ES']`
- `options.js` 中 `translations['ja-JP']`
- `popup.js` 中 `popupTranslations['es-ES']`
- `popup.js` 中 `popupTranslations['ja-JP']`

### 语言选择器

设置页语言选项：

```text
自动检测
简体中文
English
Español
日本語
```

内部值：

```text
auto
zh-CN
en-US
es-ES
ja-JP
```

### 自动检测

语言自动检测规则：

```text
zh* -> zh-CN
es* -> es-ES
ja* -> ja-JP
其他 -> en-US
```

## 设置页 UI 规格

### 高级功能区域

设置页新增“高级功能”区域，放在基础按钮样式之后、关于插件之前。

建议结构：

```text
高级功能
────────────────────────
页面进度条
启用状态：v2.1 起在工具栏 Popup 中按当前主域名设置

显示样式
(•) 进度按钮，显示在上下按钮之间
( ) 页面顶部/底部横向进度条

进度按钮设置
高度 [ 72 px ]
颜色 ( 跟随顶部按钮 | 跟随底部按钮 | 自定义 )

横向进度条设置
位置 ( 顶部 | 底部 )
粗细 [ 3 px ]
颜色 [ #4A9EDD ]

[✓] 点击跳转
[ ] 显示百分比
[ ] 显示剩余阅读时间

[ ] 自定义按钮图标
图标样式 [ 默认箭头 ] [ 三角形 ] [ 折线箭头 ] [ 极简箭头 ] [ 双箭头 ]
图标颜色 [ #FFFFFF ]
```

### 网站启用状态区域

建议独立为一个设置组：

```text
网站启用状态
────────────────────────
搜索域名 [                 ]

domain.com        开启/关闭    删除

[添加域名] [清除已关闭站点] [恢复全部启用]
```

## 验收标准

### 默认状态

- 新安装后高级功能全部关闭。
- 升级旧用户后高级功能全部关闭。
- 默认页面仍只显示两个按钮。
- 默认按钮图标仍为白色上/下箭头。

### 阅读进度条

- 开启纵向进度按钮后，按钮组显示为上按钮、进度按钮、下按钮。
- 纵向进度按钮宽度、形状、间距、透明度跟随现有按钮设置。
- 纵向进度按钮高度可配置。
- 点击纵向进度按钮顶部附近跳到页面靠近底部的位置。
- 点击纵向进度按钮底部附近跳到页面靠近顶部的位置。
- 开启横向进度条后，顶部或底部显示进度条。
- 点击横向进度条左侧跳到页面靠近顶部的位置。
- 点击横向进度条右侧跳到页面靠近底部的位置。
- 滚动页面时进度实时更新。
- 页面不可滚动时不报错。
- 全屏时进度条隐藏。
- 站点禁用时进度条移除。

### 图标自定义

- 关闭图标自定义时保持当前图标。
- 开启后可切换至少 5 套 SVG 图标。
- 图标颜色可修改。
- 图标颜色不影响按钮背景色。
- 无效颜色回退到默认白色。

### 网站管理

- 设置页能展示 `enableStates` 中的站点。
- 可搜索站点。
- 可添加 hostname。
- 输入 URL 可解析为 hostname。
- 可删除单条规则。
- 可恢复全部启用。
- Popup 与内容脚本状态同步。

### 语言

- 设置页可选择西班牙语和日语。
- Popup 可显示西班牙语和日语文案。
- 浏览器语言为 `es-*` 时自动选择西班牙语。
- 浏览器语言为 `ja-*` 时自动选择日语。
- 未匹配语言回退英文。
