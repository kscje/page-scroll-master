# v1.9 Reading & Language 功能规格

本文档定义 Page Scroll Master v1.9 的产品行为、默认值、存储结构、UI 规则和验收标准。v1.9 建议在 v1.8 Advanced Controls 完成后开发。

## 版本目标

v1.9 重点补齐两个方向：

- 滚动位置书签：帮助用户恢复或返回上次阅读位置。
- 多语言扩展：新增德语、法语、葡萄牙语、繁体中文、韩语、意大利语。

## 非目标

以下功能不纳入 v1.9：

- 智能段落跳转和目录面板
- 自动滚动/演示模式
- 滚动热力图
- 页面 Mini-Map
- 建议&反馈提交模块
- 反馈服务后端
- 反馈图片上传
- 自动上传用户页面 URL 或其他浏览数据

建议&反馈提交模块已从 v1.9 移出，延后到 v2.2 规划。v2.2 目标是使用服务端反馈入口实现扩展内直接提交，并将反馈内容发送到开发者邮箱。

## 兼容性要求

- v1.8 的高级功能默认状态和行为不得被破坏。
- 用户未开启滚动位置书签时，不显示恢复提示或返回点。
- 新增语言不得影响已有语言显示。

## 功能一：滚动位置书签

本节为早期设想。滚动位置书签的最终 V1.9 产品边界、数据结构、URL 归一化和恢复流程，以 `doc/v1.9-scroll-position-bookmarks-prd-zh.md` 为准。

### 产品目标

解决长页面、技术文档、小说、Wiki 页面中“找不到上次看到哪”的问题。

### 开关

设置项：

```js
advancedSettings.readingPosition.enabled
```

默认值：`false`

关闭时：

- 不记录页面位置。
- 不显示恢复提示。
- 不显示返回点。
- 不绑定自动保存监听。

### 默认设置

```js
readingPosition: {
  enabled: false,
  saveMode: 'beforeJump',
  restoreMode: 'prompt',
  retentionDays: 30
}
```

字段说明：

- `saveMode = 'beforeJump'`：仅在用户点击顶部/底部/进度跳转前记录当前位置。
- `saveMode = 'auto'`：自动防抖记录当前页面阅读位置。
- `restoreMode = 'prompt'`：页面打开时显示恢复提示。
- `restoreMode = 'auto'`：页面打开后自动恢复。
- `restoreMode = 'manual'`：仅提供手动恢复入口。

v1.9 推荐默认：

```text
saveMode: beforeJump
restoreMode: prompt
retentionDays: 30
```

### 存储

使用 `chrome.storage.local`，不要使用 `chrome.storage.sync`。

建议 key：

```js
readingPositions: {
  '<normalized-url>': {
    top: 1234,
    range: 9000,
    progress: 0.137,
    updatedAt: 1710000000000,
    hostname: 'example.com'
  }
}
```

URL 归一化建议：

- 使用 `location.origin + location.pathname`
- 默认不包含 hash
- 默认不包含 query，避免搜索、跟踪参数导致记录过多
- 后续可按站点配置是否包含 query

### 返回上次位置

点击顶部、底部或进度条跳转前，应记录跳转前的位置。跳转后显示一个小返回点：

```text
┌──────┐
│  ▲   │
└──────┘

●  ← 返回上次位置

┌──────┐
│  ▼   │
└──────┘
```

返回点规则：

- 仅在 `readingPosition.enabled = true` 且有可返回位置时显示。
- 点击后平滑滚动回记录位置。
- 返回点应跟随按钮组位置。
- 全屏时隐藏。
- 站点禁用时移除。

### 页面恢复提示

当页面存在历史位置，且 `restoreMode = 'prompt'` 时，显示轻提示：

```text
┌────────────────────┐
│ 恢复到上次阅读位置？ │
│ [恢复]        [忽略] │
└────────────────────┘
```

规则：

- 不应阻塞页面操作。
- 用户点击恢复后调用 `smoothScrollTo()`。
- 用户点击忽略后本次页面生命周期不再提示。
- 记录距离顶部过近或页面高度变化过大时不提示。

### 自动保存

`saveMode = 'auto'` 时：

- 滚动时防抖保存，建议 1000ms。
- 只在页面可滚动时保存。
- 不要每帧写 storage。
- 页面隐藏或卸载时可保存一次。

### 过期清理

按 `retentionDays` 清理旧记录。

建议在以下时机清理：

- 设置页打开时
- 内容脚本初始化时低频触发
- 保存新记录前

## 功能二：新增多语言支持

### 新增语言

v1.9 新增：

- 德语：`de-DE`
- 法语：`fr-FR`
- 葡萄牙语：`pt-BR`
- 繁体中文：`zh-TW`
- 韩语：`ko-KR`
- 意大利语：`it-IT`

### Chrome locale 文件

新增：

```text
_locales/de/messages.json
_locales/fr/messages.json
_locales/pt_BR/messages.json
_locales/zh_TW/messages.json
_locales/ko/messages.json
_locales/it/messages.json
```

### 语言选择器

设置页语言选项：

```text
自动检测
简体中文
繁體中文
English
Español
日本語
Deutsch
Français
Português
한국어
Italiano
```

内部值：

```text
auto
zh-CN
zh-TW
en-US
es-ES
ja-JP
de-DE
fr-FR
pt-BR
ko-KR
it-IT
```

### 自动检测

语言归一化规则：

```text
zh-TW / zh-HK / zh-Hant -> zh-TW
zh-*                    -> zh-CN
en-*                    -> en-US
es-*                    -> es-ES
ja-*                    -> ja-JP
de-*                    -> de-DE
fr-*                    -> fr-FR
pt-*                    -> pt-BR
ko-*                    -> ko-KR
it-*                    -> it-IT
其他                    -> en-US
```

### 必须同步的位置

- `_locales/*/messages.json`
- `options.js` 中的 `translations`
- `popup.js` 中的 `popupTranslations`
- `options.html` 的语言选择器
- README 语言支持说明

## 延后功能：建议&反馈提交模块

建议&反馈提交模块不纳入 v1.9。原因：

- 目标体验是用户点击确认后即提交成功，不依赖用户本地邮件客户端。
- 该体验需要服务端反馈入口或第三方邮件服务，不能用 `mailto` 满足。
- 支持图片上传、服务端转发到邮箱、限流和反垃圾处理会显著增加实现与合规成本。
- 当前阶段优先完成滚动位置书签和多语言扩展，反馈提交服务延后到用户量达到一定规模后再开发。

v2.2 规划边界：

- 扩展内表单直接提交到反馈服务端。
- 服务端将反馈内容发送到开发者邮箱。
- 支持用户主动上传图片。
- 页面 URL 默认不附带；用户勾选后尽力读取并上传，读取失败时降级为空或 `unavailable`。
- 更新隐私政策，明确反馈内容、图片和可选页面 URL 的处理方式。
- 新增必要的远程请求权限，并限定到反馈服务域名。

## 验收标准

### 滚动位置书签

- 默认关闭。
- 关闭时不记录、不提示、不显示返回点。
- 点击顶部/底部跳转前可记录当前位置。
- 跳转后返回点显示正确。
- 点击返回点可回到记录位置。
- 页面存在历史记录时可显示恢复提示。
- 忽略恢复后本次页面不再提示。
- 自动保存模式不会频繁写 storage。
- 过期记录会清理。

### 多语言

- 新增 6 个 `_locales` 文件夹和 messages 文件。
- 设置页可选择 6 种新增语言。
- Popup 可显示 6 种新增语言。
- 自动检测规则正确。
- 未识别语言回退英文。
