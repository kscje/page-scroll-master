# v1.9 Reading & Feedback 功能规格

本文档定义 Page Scroll Master v1.9 的产品行为、默认值、存储结构、UI 规则和验收标准。v1.9 建议在 v1.8 Advanced Controls 完成后开发。

## 版本目标

v1.9 重点补齐三个方向：

- 滚动位置书签：帮助用户恢复或返回上次阅读位置。
- 多语言扩展：新增德语、法语、葡萄牙语、繁体中文、韩语、意大利语。
- 建议&反馈模块：在设置页提供更明显、更易用的反馈入口。

## 非目标

以下功能不纳入 v1.9：

- 智能段落跳转和目录面板
- 自动滚动/演示模式
- 滚动热力图
- 页面 Mini-Map
- 真实后端反馈管理后台
- 静默发送邮件
- 自动上传用户页面 URL 或其他浏览数据

## 兼容性要求

- v1.8 的高级功能默认状态和行为不得被破坏。
- 用户未开启滚动位置书签时，不显示恢复提示或返回点。
- 新增语言不得影响已有语言显示。
- 反馈模块不得新增网络权限。
- 反馈模块不得默认收集当前页面 URL。

## 功能一：滚动位置书签

### 产品目标

解决长页面、技术文档、小说、Wiki 页面中“找不到上次看到哪”的问题。

### 开关

设置项：

```js
advancedSettings.readingPosition.enabled
```

默认值：`false`

关闭时：

- 不记录页面位置。
- 不显示恢复提示。
- 不显示返回点。
- 不绑定自动保存监听。

### 默认设置

```js
readingPosition: {
  enabled: false,
  saveMode: 'beforeJump',
  restoreMode: 'prompt',
  retentionDays: 30
}
```

字段说明：

- `saveMode = 'beforeJump'`：仅在用户点击顶部/底部/进度跳转前记录当前位置。
- `saveMode = 'auto'`：自动防抖记录当前页面阅读位置。
- `restoreMode = 'prompt'`：页面打开时显示恢复提示。
- `restoreMode = 'auto'`：页面打开后自动恢复。
- `restoreMode = 'manual'`：仅提供手动恢复入口。

v1.9 推荐默认：

```text
saveMode: beforeJump
restoreMode: prompt
retentionDays: 30
```

### 存储

使用 `chrome.storage.local`，不要使用 `chrome.storage.sync`。

建议 key：

```js
readingPositions: {
  '<normalized-url>': {
    top: 1234,
    range: 9000,
    progress: 0.137,
    updatedAt: 1710000000000,
    hostname: 'example.com'
  }
}
```

URL 归一化建议：

- 使用 `location.origin + location.pathname`
- 默认不包含 hash
- 默认不包含 query，避免搜索、跟踪参数导致记录过多
- 后续可按站点配置是否包含 query

### 返回上次位置

点击顶部、底部或进度条跳转前，应记录跳转前的位置。跳转后显示一个小返回点：

```text
┌──────┐
│  ▲   │
└──────┘

●  ← 返回上次位置

┌──────┐
│  ▼   │
└──────┘
```

返回点规则：

- 仅在 `readingPosition.enabled = true` 且有可返回位置时显示。
- 点击后平滑滚动回记录位置。
- 返回点应跟随按钮组位置。
- 全屏时隐藏。
- 站点禁用时移除。

### 页面恢复提示

当页面存在历史位置，且 `restoreMode = 'prompt'` 时，显示轻提示：

```text
┌────────────────────┐
│ 恢复到上次阅读位置？ │
│ [恢复]        [忽略] │
└────────────────────┘
```

规则：

- 不应阻塞页面操作。
- 用户点击恢复后调用 `smoothScrollTo()`。
- 用户点击忽略后本次页面生命周期不再提示。
- 记录距离顶部过近或页面高度变化过大时不提示。

### 自动保存

`saveMode = 'auto'` 时：

- 滚动时防抖保存，建议 1000ms。
- 只在页面可滚动时保存。
- 不要每帧写 storage。
- 页面隐藏或卸载时可保存一次。

### 过期清理

按 `retentionDays` 清理旧记录。

建议在以下时机清理：

- 设置页打开时
- 内容脚本初始化时低频触发
- 保存新记录前

## 功能二：新增多语言支持

### 新增语言

v1.9 新增：

- 德语：`de-DE`
- 法语：`fr-FR`
- 葡萄牙语：`pt-BR`
- 繁体中文：`zh-TW`
- 韩语：`ko-KR`
- 意大利语：`it-IT`

### Chrome locale 文件

新增：

```text
_locales/de/messages.json
_locales/fr/messages.json
_locales/pt_BR/messages.json
_locales/zh_TW/messages.json
_locales/ko/messages.json
_locales/it/messages.json
```

### 自动检测

语言归一化规则：

```text
zh-TW / zh-HK / zh-Hant -> zh-TW
zh-*                    -> zh-CN
en-*                    -> en-US
es-*                    -> es-ES
ja-*                    -> ja-JP
de-*                    -> de-DE
fr-*                    -> fr-FR
pt-*                    -> pt-BR
ko-*                    -> ko-KR
it-*                    -> it-IT
其他                    -> en-US
```

### 必须同步的位置

- `_locales/*/messages.json`
- `options.js` 中的 `translations`
- `popup.js` 中的 `popupTranslations`
- `options.html` 的语言选择器
- README 语言支持说明
- 新增 v1.9 反馈模块所有文案

## 功能三：建议&反馈模块

### 产品目标

在设置页提供独立的“建议&反馈”分类，让用户可以更容易提交建议、问题反馈和功能请求。

### 方案选择

v1.9 推荐邮件反馈方案，不做专门建议管理后台。

原因：

- 当前项目没有后端服务。
- 邮件方案不需要新增网络权限。
- 邮件方案隐私风险低，符合当前插件轻量、隐私友好的定位。
- 专门管理后台需要服务端、数据库、认证、反垃圾、隐私政策更新和长期维护。

### 邮件反馈行为

用户在设置页填写表单，点击“发送邮件”后：

- 构造 `mailto:kscj.ty@gmail.com`
- 预填 subject 和 body
- 通过 `window.location.href` 或创建临时链接打开邮件客户端

注意：浏览器扩展不能在无后端、无用户确认的情况下直接发送邮件。文案应避免承诺“已发送成功”。

### 备用复制

必须提供“复制内容”按钮：

- 当 `mailto` 不可用时，用户可以复制反馈内容。
- 复制成功后显示短提示。

### 表单字段

```text
建议&反馈
────────────────────────
反馈类型
[ 功能建议 v ]

你的建议
[                                      ]
[                                      ]
[                                      ]

联系方式（可选）
[ your@email.com                      ]

[ ] 附带当前页面 URL 和浏览器语言

[发送邮件] [复制内容]
```

反馈类型建议：

- 功能建议
- 问题反馈
- 兼容性问题
- 翻译问题
- 其他

### 隐私规则

- 默认不附带当前页面 URL。
- 默认不附带用户邮箱。
- 联系方式由用户主动填写。
- 反馈内容不保存到 storage。
- 不发送网络请求。
- 如用户勾选“附带当前页面 URL 和浏览器语言”，才把当前页面 URL 写入邮件正文。

### 邮件内容

主题：

```text
[Page Scroll Master Feedback] 功能建议
```

正文：

```text
Feedback Type:
功能建议

Message:
...

Contact:
...

Environment:
Extension Version: 1.9.0
Language: zh-CN
Browser Language: zh-CN
Page URL: 仅用户勾选后附带
```

### 设置页位置

建议将“建议&反馈”作为独立设置组，放在“网站启用状态”之后、“关于插件”之前。

## 验收标准

### 滚动位置书签

- 默认关闭。
- 关闭时不记录、不提示、不显示返回点。
- 点击顶部/底部跳转前可记录当前位置。
- 跳转后返回点显示正确。
- 点击返回点可回到记录位置。
- 页面存在历史记录时可显示恢复提示。
- 忽略恢复后本次页面不再提示。
- 自动保存模式不会频繁写 storage。
- 过期记录会清理。

### 多语言

- 新增 6 个 `_locales` 文件夹和 messages 文件。
- 设置页可选择 6 种新增语言。
- Popup 可显示 6 种新增语言。
- 自动检测规则正确。
- 新增反馈模块文案有全部语言翻译。
- 未识别语言回退英文。

### 建议&反馈

- 设置页有“建议&反馈”分类。
- 用户可选择反馈类型。
- 用户可输入反馈内容。
- 内容为空时不允许发送，并显示提示。
- 点击发送邮件会打开预填 `mailto:`。
- 点击复制内容可复制反馈正文。
- 默认不包含当前页面 URL。
- 勾选后才包含当前页面 URL 和浏览器语言。
- 不新增网络权限。
