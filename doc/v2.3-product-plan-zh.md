# v2.3 Auto Reading & Page Navigation Update 产品规划

本文档定义 Page Scroll Master v2.3 的整体产品范围。v2.3 在顶部/底部、按屏跳转、书签和智能段落导航能力之上，补充自动滚屏播放、条件式分页导航，以及俄语、土耳其语和印度尼西亚语支持。

## 版本目标

v2.3 聚焦三项能力：

1. 新增面向长文章、文档、小说和演示场景的自动滚屏播放。
2. 在智能段落跳转窗口内提供高置信度的上一页、下一页导航，不增加常驻浮动按钮。
3. 新增俄语、土耳其语和印度尼西亚语，将支持语言从 10 种扩展到 13 种。

## 非目标

- 不实现无人值守的跨页面连续自动播放。
- 不默认在页面加载、浏览器启动或书签恢复后自动开始滚动。
- 不将自动滚屏运行状态同步到其他设备或跨标签页恢复。
- 不仅凭全页面出现“上一页”“下一页”文字就执行分页跳转。
- 不为上一页、下一页增加独立浮动按钮。
- 不递归分析关闭的 Shadow DOM、iframe 或跨域页面内容。
- 不加入阿拉伯语等需要完整 RTL 布局改造的语言。

## 功能一：自动滚屏播放

### 产品目标

让用户在阅读长文章、技术文档、小说或进行提词和演示时，以稳定速度连续向下滚动，并能随时暂停、继续或停止。

该能力的差异化重点是：

- 复用现有主要滚动容器检测，兼容根页面和自定义滚动容器。
- 与页面进度、书签和当前章节高亮联动。
- 提供明确的智能暂停规则，而不只是简单定时修改 `scrollTop`。

### 入口与默认体验

- 自动滚屏属于独立高级功能，默认关闭。
- 是否在当前主域名启用由 Popup 管理。
- 启用后显示一个独立的播放/暂停按钮，不分别创建播放、暂停、加速和减速按钮。
- 播放按钮位置支持页面顶部、页面底部或上/下主按钮之间，复用现有阅读工具位置体系。
- 详细速度和暂停规则在设置页配置。
- Popup 可显示当前标签页的播放或暂停状态，但不在 Popup 关闭后终止播放。
- 页面刷新、标签页关闭、站点总开关关闭或扩展重新加载后恢复为停止状态。

### 播放状态

运行状态只保存在当前内容脚本内存中：

```js
autoScrollState: 'stopped' | 'playing' | 'paused'
```

状态规则：

- `stopped`：没有活动动画，下一次点击从当前位置开始。
- `playing`：按配置速度连续向下滚动。
- `paused`：保留当前位置和播放参数，点击后继续。
- 到达页面底部后进入 `stopped`。
- SPA 路由变化、主要滚动容器失效或站点功能被关闭时进入 `stopped`。
- 不把播放、暂停状态写入 `chrome.storage.sync` 或 `chrome.storage.local`。

### 速度模式

v2.3 首版提供像素速度模式，不扫描全文计算真实阅读速度：

```text
慢速       20 px/s
标准       40 px/s
快速       80 px/s
自定义     10-300 px/s
```

默认速度为 `40 px/s`。

实现规则：

- 使用 `requestAnimationFrame` 和经过时间计算位移，不使用固定间隔累加。
- 速度不依赖显示器刷新率。
- 页面短暂卡顿后限制单帧最大位移，避免突然大幅跳动。
- 播放期间沿当前主要滚动容器向下移动，不自动反向。
- 速度设置变化对正在播放的当前页面立即生效。
- “每分钟字数”可作为后续增强；v2.3 不在滚动事件或动画帧中扫描全文。

### 智能暂停与停止

以下行为默认暂停：

- 用户滚轮滚动。
- 用户触摸滚动或拖动滚动条。
- 用户选中文本。
- 输入框、文本框、下拉框或可编辑区域获得焦点。
- 页面进入隐藏状态或标签页失去可见性。
- 页面进入全屏或检测到正在播放的主要视频。

以下行为停止：

- 到达页面底部。
- 用户点击停止操作。
- 当前主域名关闭自动滚屏或关闭插件总开关。
- SPA 路由变化导致页面内容切换。
- 当前滚动容器被移除且重试后仍无法解析。

用户通过顶部、底部、上一屏、下一屏、进度条、书签或目录主动跳转时，自动滚屏先暂停；跳转完成后不自动恢复，等待用户确认继续。

### 与现有阅读功能联动

- 播放期间继续更新页面进度条和百分比。
- 智能段落窗口打开时暂停播放，关闭窗口后不自动恢复。
- 章节高亮继续根据实际滚动位置更新。
- 保存书签前暂停，保存完成后由用户决定是否继续。
- 恢复书签后保持暂停。
- 全屏隐藏规则只控制按钮可见性，不代表后台继续无人值守播放；进入全屏默认暂停。

### 按钮与菜单

自动滚屏仅提供一个播放控制按钮：

```text
停止状态     ▶
播放状态     ❚❚
暂停状态     ▶
```

- 长按或右键不承载关键功能。
- 速度调节放在设置页或按钮弹出的紧凑菜单中。
- 按钮必须提供本地化 `aria-label`、`title` 和当前状态。
- 不在主按钮组中增加独立的加速、减速、暂停和停止按钮。

### 设置结构建议

详细参数保存在 `chrome.storage.sync`：

```js
advancedSettings: {
  autoScroll: {
    speed: 40,
    buttonPosition: 'pageBottom',
    buttonColorMode: 'followTopButton',
    buttonCustomColor: '#4A9EDD',
    pauseOnUserScroll: true,
    pauseOnTextSelection: true,
    pauseOnEditableFocus: true,
    pauseWhenPageHidden: true,
    pauseOnFullscreenOrVideo: true
  }
}
```

主域名启用状态保存在 `chrome.storage.local`：

```js
domainFeatureStates: {
  'example.com': {
    extensionEnabled: true,
    features: {
      autoScroll: true
    }
  }
}
```

兼容规则：

- 旧用户缺少 `autoScroll` 设置和主域名状态时默认关闭。
- 详细参数通过深合并补齐，不要求用户清空 storage。
- 播放状态和当前滚动位置不写入设置。
- 不新增网络权限。

### 验收标准

- 根页面和自定义滚动容器均以稳定速度连续滚动。
- 不同刷新率下单位时间位移基本一致。
- 用户滚轮、触摸、选择文本、编辑输入和切换标签页时按规则暂停。
- 到达底部后停止且不持续占用动画帧。
- SPA 路由变化和滚动容器替换后不会继续操作失效节点。
- 进度、书签、目录和按屏跳转与自动播放状态转换一致。
- 重复启停不产生重复按钮、事件监听器或动画循环。
- 功能默认关闭，升级后不改变现有页面体验。

## 功能二：上一页和下一页导航

### 产品目标

在分页文章、小说、论坛、搜索结果或多页文档中，为用户提供上一页、下一页入口，同时避免将更多方向按钮加入页面浮动按钮组。

### 入口

上一页、下一页仅内嵌在智能段落跳转窗口的固定操作区：

```text
页面目录

[← 上一页]  [下一页 →]

[上一段]    [下一段]
────────────────────
目录列表
```

显示规则：

- 至少识别到一个高置信度分页目标时才显示“页面导航”区域。
- 只识别到上一页时，隐藏或禁用下一页。
- 只识别到下一页时，隐藏或禁用上一页。
- 两个目标都不存在时，不显示整个区域。
- 不新增独立浮动按钮，不占用主按钮组位置。
- 智能段落跳转功能未启用时，不单独显示分页导航入口。

### 识别优先级

按以下顺序寻找候选目标：

1. 文档头部 `<link rel="prev">` 和 `<link rel="next">`。
2. 可见链接 `<a rel="prev">` 和 `<a rel="next">`。
3. 明确分页容器中的可见链接，例如 `nav`、`[role="navigation"]` 或带分页语义的容器。
4. 同一分页容器中具有明确语言文本或 `aria-label` 的上一页、下一页控件。

不得仅通过全页面模糊搜索“上一页”“下一页”“Prev”“Next”并选择第一个结果。

### 置信度与过滤

- 目标必须是可导航的同页或 HTTP/HTTPS URL。
- 排除隐藏、禁用、无 `href`、`javascript:`、下载链接和明显广告链接。
- 排除轮播图、媒体播放列表、评论分页和非主要内容区域，除非存在标准 `rel` 语义。
- 优先选择主要内容或主要分页导航附近的候选。
- 同一个 URL 不得同时作为上一页和下一页。
- 候选冲突或置信度不足时宁可不显示，不猜测跳转。
- 不将解析出的 URL 写入 storage、匿名统计或远程服务。

### 点击行为

- 点击后使用正常页面导航，不在扩展内抓取或预加载目标内容。
- 同站点和跨站点链接均按页面原始 URL 导航，但跨主域名时在按钮辅助文本中显示目标主域名。
- 自动滚屏正在播放时先停止，再执行导航。
- 当前页面存在未保存阅读位置时不强制自动创建书签。
- 导航失败由浏览器正常处理，扩展不无限重试。
- 支持键盘聚焦、Enter/Space 激活和明确的 `aria-label`。

### 多语言识别

标准 `rel` 语义优先，不依赖界面语言。

文本候选至少覆盖当前和 v2.3 新增语言中的明确分页词：

- 中文：上一页、下一页
- 英文：Previous page、Next page
- 西班牙语：Página anterior、Página siguiente
- 日语：前のページ、次のページ
- 德语：Vorherige Seite、Nächste Seite
- 法语：Page précédente、Page suivante
- 葡萄牙语：Página anterior、Próxima página
- 韩语：이전 페이지、다음 페이지
- 意大利语：Pagina precedente、Pagina successiva
- 俄语：Предыдущая страница、Следующая страница
- 土耳其语：Önceki sayfa、Sonraki sayfa
- 印度尼西亚语：Halaman sebelumnya、Halaman berikutnya

文本匹配必须结合分页容器、可见性和链接属性，不能单独作为高置信度依据。

### 缓存与 SPA

- 分页候选随智能段落目录快照一起按需解析。
- 菜单关闭时不持续扫描页面。
- URL、有效 DOM 或主要滚动容器变化时使分页快照失效。
- 菜单打开期间发生有效变化时防抖后刷新按钮。
- 不建立跨页面长期分页缓存。

### 验收标准

- 标准 `rel="prev|next"` 页面能稳定识别。
- 明确分页导航容器可以在多语言文本下识别。
- 轮播图、推荐区、评论区和普通“下一步”按钮不会被误识别。
- 无可靠目标时完全隐藏页面导航区域。
- 只显示存在且可用的方向。
- 页面导航不会新增浮动按钮或改变现有按钮组布局。
- SPA 和动态分页控件变化后结果能够刷新。
- 分页 URL 不进入 storage、匿名统计或反馈 payload。

## 功能三：新增三种语言

### 支持范围

v2.3 新增：

- 俄语：`ru-RU`，Chrome locale 目录 `_locales/ru/`
- 土耳其语：`tr-TR`，Chrome locale 目录 `_locales/tr/`
- 印度尼西亚语：`id-ID`，Chrome locale 目录 `_locales/id/`

新增后共支持 13 种语言。

### 必须同步的位置

- `options.js` 的 Options 翻译表和 `normalizeLanguage()`。
- `popup.js` 的 Popup 翻译表和 `normalizeLanguage()`。
- `options.html` 的语言选择器。
- `_locales/ru/messages.json`。
- `_locales/tr/messages.json`。
- `_locales/id/messages.json`。
- Manifest、命令说明、内容脚本及 Chrome 原生界面的 locale key。
- 设置页快速开始、更新记录、匿名统计、v2.2 和 v2.3 新功能文案。
- README、商店文案和发布检查清单中的语言数量与列表。

### 自动检测

```text
ru-* -> ru-RU
tr-* -> tr-TR
id-* -> id-ID
```

- 未识别语言继续回退 `en-US`。
- 保存的显式语言优先于浏览器自动检测。
- Options、Popup 和内容脚本必须返回一致的规范语言代码。
- 不使用 `in` 作为印度尼西亚语代码；统一使用现代 BCP 47 代码 `id`。

### 本地化质量

- 语言名称在选择器中使用本地写法：`Русский`、`Türkçe`、`Bahasa Indonesia`。
- 不直接提交未经检查的机器翻译。
- 检查俄语较长文本对按钮、表格和更新记录布局的影响。
- 检查土耳其语大小写和带附加符号字符。
- 检查印度尼西亚语长复合短语在 Popup 窄宽度下的换行。
- 三种语言均为从左到右布局，不引入 RTL 改造。
- locale key 集合必须与现有 `_locales/en/messages.json` 完全对齐。

### 验收标准

- 三种语言都能通过设置页手动选择。
- 浏览器语言为 `ru-*`、`tr-*`、`id-*` 时自动检测正确。
- Options、Popup、内容脚本、Manifest 和命令说明没有缺失文案。
- 切换语言后新增功能文案同步更新。
- Popup 窄窗口、设置页卡片和域名状态表没有截断关键操作。
- `node tests/test-language-normalization.js` 覆盖并通过 13 种语言。

## 隐私与权限

- 自动滚屏只处理当前页面滚动状态，不发送页面内容或阅读行为。
- 分页识别只在当前页面内存中处理，不保存或上传候选 URL。
- 新增语言不引入网络请求。
- v2.3 不因自动滚屏或分页导航新增 Chrome 权限。
- 如果匿名统计需要新增自动滚屏或分页操作事件，必须先更新 allowlist、用户预览、隐私文案和商店披露；不允许直接透传 URL、标题或页面结构。

## 建议实施顺序

1. 建立自动滚屏默认值、状态机和纯速度计算 helper。
2. 实现根页面与自定义滚动容器播放、暂停、停止和清理。
3. 接入 Popup 主域名开关、播放按钮、设置页配置和现有阅读工具联动。
4. 建立分页候选解析、置信度过滤和智能段落窗口 UI。
5. 补齐 SPA、动态 DOM 和分页误识别回归测试。
6. 新增俄语、土耳其语、印度尼西亚语及 13 语言一致性测试。
7. 更新 README、CHANGELOG、商店资料并完成真实 Chrome 验收。

## v2.3 完成定义

v2.3 只有在以下条件满足时才算完成：

- 自动滚屏默认关闭，并在根页面和自定义滚动容器中稳定运行。
- 播放状态机、智能暂停、页面底部停止和生命周期清理行为正确。
- 上一页、下一页只在智能段落跳转窗口内按高置信度条件显示。
- 分页导航不会增加常驻浮动按钮或明显增加页面操作复杂度。
- 俄语、土耳其语和印度尼西亚语完成 Options、Popup、内容脚本和 Chrome locale 全覆盖。
- 旧用户设置和主域名状态通过深合并保持兼容。
- 不新增不必要权限，不上传页面内容、分页 URL 或阅读位置。
- 对应 Node 回归、真实 Chrome 自动播放、分页识别和多语言视觉验收通过。
