# Smart Scroll Navigator – Top, Bottom & Progress

一个 Chrome 扩展，用于快速跳转到页面顶部或底部，显示阅读进度，并提供长页面快速定位、浮动按钮、工具栏弹窗、快捷键和可视化设置页。

## 功能

- 一键滚动到页面顶部或底部
- 智能滚动容器检测：自动适配使用自定义滚动容器（如飞书 Wiki、Notion、语雀、钉钉文档等 SPA 页面）
- 浮动按钮常驻页面边缘
- 可按主域名停用“跳转到顶部/底部”按钮，同时继续使用页面进度条等高级功能和全局快捷键
- 工具栏弹窗内可按当前主域名控制整个扩展，以及页面进度条、滚动位置书签和智能段落跳转
- 设置页集中管理主域名功能状态：支持搜索、添加、删除、切换、清除已关闭站点和清除全部记录
- 设置页高级功能按模块折叠，支持恢复基础按钮、单个高级模块或全部同步设置默认值
- 全局快捷键支持
  - `Ctrl+Shift+Up` / `Command+Shift+Up`
  - `Ctrl+Shift+Down` / `Command+Shift+Down`
- 三种滚动模式：立即跳转、浏览器原生顺滑滚动和自定义动画；新用户默认立即跳转
- 自定义动画时长可在 `10ms - 2000ms` 之间调整；历史用户原有滚动速度会迁移为自定义模式
- 可自定义按钮位置
  - 左侧 / 右侧
  - 顶部 / 居中 / 底部
- 可自定义按钮尺寸、形状、间距、颜色和透明度（尺寸 10px - 120px，间距 0px - 800px，透明度 0% - 100%）
- 按钮形状可选：圆形（Round）或正方形（Square）
- 鼠标悬停 + 指定快捷键隐藏按钮
- 高级页面进度条（默认关闭）：支持按钮组内纵向进度按钮，或页面顶部/底部横向进度条
- 点击进度条快速跳转到页面任意位置（可关闭）
- 滚动位置书签（默认关闭）：通过独立书签按钮手动保存当前阅读位置，并可选择再次打开页面时自动加载、提示恢复或手动加载
- 已保存位置管理：支持在设置页查看、打开和删除滚动位置书签
- 智能段落跳转（默认关闭）：通过独立目录按钮展示页面目录、上一段、下一段和当前章节高亮
- 自动滚屏（默认关闭）：通过独立播放按钮以稳定速度向下滚动，并在用户操作、选中文字、编辑输入、切换标签页、全屏或主要视频播放时暂停
- 按钮图标样式与图标颜色自定义（默认关闭，内置 5 套 SVG 图标）
- 全屏模式自动隐藏按钮
- 扩展内建议与反馈：可主动提交反馈类型、内容、可选联系方式和最多 3 张图片
- 卸载调研（自愿）：卸载后可打开轻量反馈页，只有主动提交后才发送所选原因、可选说明和可选联系方式
- Chrome Web Store 评分入口：在满足本地频控后于 Popup 底部轻量邀请评分，并在设置页提供常驻评分入口
- 中文、繁体中文、英文、西班牙语、日语、德语、法语、葡萄牙语、韩语、意大利语、俄语、土耳其语和印度尼西亚语界面支持
- 设置页实时预览
- 图标生成工具

## 安装

1. 下载或克隆本项目
2. 打开 Chrome 的扩展程序页面：`chrome://extensions/`
3. 开启“开发者模式”
4. 点击“加载已解压的扩展程序”
5. 选择本项目根目录

### 图标

如果你想重新生成图标，可以先打开 `create-icons.html`，生成后放入 `icons/` 目录：

- `icon16.png`
- `icon32.png`
- `icon48.png`
- `icon128.png`

## 使用

### 浮动按钮

- 点击上方箭头滚动到顶部
- 点击下方箭头滚动到底部

### 工具栏弹窗

点击扩展图标后，可针对当前主域名启用或停用扩展、启用或停用“跳转到顶部/底部”按钮，并分别控制页面进度条、滚动位置书签和智能段落跳转，也可以打开设置页。

主域名状态会保存在 `chrome.storage.local` 中。同一可注册主域名下的不同子域名和页面共享状态。
新安装后，未单独设置的网站默认启用；可在“基础设置”中改为默认关闭。手动设置的主域名状态始终优先于该默认行为。

### 快捷键

- 顶部：`Ctrl+Shift+Up` / `Command+Shift+Up`
- 底部：`Ctrl+Shift+Down` / `Command+Shift+Down`

## 设置项

在设置页中可以调整：

- 滚动模式：立即、顺滑或自定义；自定义模式可调整 `10ms - 2000ms` 动画时长
- 新网站默认启用或默认关闭（仅影响未单独设置的网站）
- 按主域名启用或停用“跳转到顶部/底部”按钮；停用后高级功能和全局快捷键仍可使用
- 按钮位置
- 按钮尺寸
- 按钮形状（圆形/正方形）
- 按钮间距
- 顶部按钮颜色
- 底部按钮颜色
- 透明度
- 鼠标悬停 + 快捷键隐藏
- 隐藏按钮所用快捷键
- 高级页面进度条
  - 纵向进度按钮 / 横向顶部或底部进度条
  - 进度颜色、粗细、高度、点击跳转和百分比显示
- 滚动位置书签
  - 独立书签按钮位置、颜色和再次打开页面时的加载方式
  - 自动加载到最新书签位置 / 仅提示恢复到书签位置 / 手动加载
  - 每域名保留最近 1 条、2 条或 3 条已保存位置
- 智能段落跳转
  - 独立目录按钮位置、颜色、目录来源、每批加载目录项、短标题过滤和当前章节高亮
- 按钮图标样式与图标颜色
- 网站启用状态管理
- 界面语言
- 恢复默认：可恢复基础按钮、页面进度条、按屏跳转、滚动位置书签、智能段落跳转、自动滚屏或全部同步设置

设置会保存在 `chrome.storage.sync` 中，并由已打开页面中的内容脚本自动响应更新。
各项高级功能是否启用由工具栏 Popup 按主域名控制；设置页只保存详细参数。
插件、主按钮可见性和高级功能的主域名状态保存在 `chrome.storage.local` 的 `domainFeatureStates` 中，不进入同步存储。
设置页高级模块折叠状态保存在 `chrome.storage.local` 中，不进入同步存储。

## 隐私

扩展不收集、存储或传输匿名使用统计数据。详细的数据处理规则见 `chrome-web-store/privacy/zh-CN.md`。

建议与反馈仅在用户点击提交后发送。反馈正文、主动填写的联系方式和主动选择的图片会经开发者运营的 Cloudflare Worker 和 Resend 邮件服务转发到开发者邮箱，不写入扩展 storage。反馈提交不读取或发送当前页面 URL 和浏览器语言。

卸载扩展后，浏览器可能打开开发者运营的自愿调研页面。页面打开本身不会提交卸载原因；只有用户点击提交后，才会发送所选原因、可选补充说明、可选联系方式、扩展版本和界面语言。服务端只保留无正文投递与限流日志，不保存补充说明、联系方式或明文 IP。

## 项目结构

- `manifest.json`：扩展配置
- `content.js`：页面内浮动按钮和滚动逻辑
- `popup.html` / `popup.js`：工具栏弹窗
- `options.html` / `options.js`：设置页
- `background.js`：快捷键处理
- `_locales/`：多语言文案
- `chrome-web-store/`：商店文案、隐私政策、发布清单和最终上传图片
- `feedback-backend/`：反馈校验、限流、无内容日志和邮件转发 Worker
- `create-icons.html` / `create-icons.js`：图标生成工具

## 注意事项

- 扩展需要访问网页内容，才能在页面中注入浮动按钮
- 某些浏览器内置页面（如 `chrome://` 页面）不支持内容脚本
- 如果快捷键冲突，可在浏览器扩展快捷键页面中调整
- 对于使用自定义滚动容器的页面，插件会自动检测并适配（检测策略：`document.scrollingElement` → 候选元素遍历 → `document.documentElement`）
