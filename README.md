# Page Scroll Master

一个功能完整的Chrome浏览器插件，实现通过鼠标点击按钮即可一键滚动到页面顶部及底部的功能，支持丰富的自定义选项和跨平台体验。

## 功能特性

- ✅ 一键滚动到页面顶部
- ✅ 一键滚动到底部
- ✅ 平滑滚动动画效果
- ✅ 可配置滚动速度 (10ms-2000ms)
- ✅ 支持快捷键操作
- ✅ 按钮常驻在网页界面
- ✅ 位置自定义设置
  - 水平位置：左侧边缘或右侧边缘
  - 垂直对齐：居中、顶部或底部
- ✅ 按钮样式自定义
  - 尺寸调整 (10px-120px)
  - 颜色自定义 (默认: #4A9EDD)
  - 透明度调节 (0-100%)
- ✅ 鼠标悬停+快捷键隐藏功能
- ✅ 跨平台快捷键命名
- ✅ 多语言支持（中文/英文）
- ✅ 响应式设计，适配不同浏览器和设备
- ✅ 全屏模式自动隐藏按钮
- ✅ 顶部设置栏固定定位
- ✅ 垂直对齐方式即刻变动调整

## 安装方法

### 方式一：使用图标生成工具（推荐）
1. 下载或克隆本项目到本地
2. 打开 `create-icons.html` 文件（在浏览器中双击打开）
3. 选择喜欢的颜色和图标样式
4. 点击"下载全部"按钮，保存所有尺寸的图标
5. 将下载的图标文件放入项目的 `icons/` 目录
6. 打开Chrome浏览器，进入扩展管理页面 (`chrome://extensions/`)
7. 开启"开发者模式"
8. 点击"加载已解压的扩展程序"
9. 选择本项目的根目录
10. 插件安装完成

### 方式二：手动创建图标
1. 下载或克隆本项目到本地
2. **创建图标文件**：在`icons`目录中创建以下尺寸的PNG图标文件：
   - `icon16.png` (16x16px) - 工具栏图标
   - `icon32.png` (32x32px) - Retina显示
   - `icon48.png` (48x48px) - 扩展管理页面
   - `icon128.png` (128x128px) - Chrome Web Store
3. 图标设计建议：
   - 使用 **PNG** 格式，支持透明度
   - 推荐使用 **#4A9EDD** 作为主色调
   - 保持设计简洁，确保在小尺寸下可识别
   - 详细设计指南请参考 [ICON_GUIDE.md](ICON_GUIDE.md)
4. 打开Chrome浏览器，进入扩展管理页面 (`chrome://extensions/`)
5. 开启"开发者模式"
6. 点击"加载已解压的扩展程序"
7. 选择本项目的根目录
8. 插件安装完成，会在浏览器工具栏显示图标，同时在网页中显示滚动按钮

## 使用方法

### 通过常驻按钮
1. 网页加载后，滚动按钮会常驻在页面边缘
2. 点击**绿色按钮**滚动到页面顶部
3. 点击**蓝色按钮**滚动到底部

### 通过工具栏图标
1. 点击浏览器工具栏中的插件图标
2. 在弹出的界面中点击"滚动到顶部"或"滚动到底部"按钮

### 通过快捷键
- **滚动到顶部**: `Ctrl+Shift+Up` (Windows/Linux) 或 `Command+Shift+Up` (Mac)
- **滚动到底部**: `Ctrl+Shift+Down` (Windows/Linux) 或 `Command+Shift+Down` (Mac)

### 鼠标悬停+快捷键隐藏
1. 启用此功能后，当鼠标悬停在按钮上并按快捷键时，按钮会平滑隐藏
2. 移开鼠标或释放快捷键后，按钮会恢复显示
3. 可在设置中选择不同的快捷键（Alt、Ctrl/Command、Shift）

## 自定义设置

1. 点击插件图标，然后点击"设置"按钮
2. 在设置页面中调整以下选项：
   - **滚动速度**：调整滚动动画的速度
   - **水平位置**：选择按钮显示在页面左侧或右侧
   - **垂直对齐**：选择按钮的垂直位置（居中、顶部、底部）
   - **按钮尺寸**：调整按钮大小（10px-120px）
   - **按钮颜色**：自定义顶部和底部按钮的颜色
   - **透明度**：调整按钮的透明度
   - **启用鼠标悬停+快捷键隐藏**：开启或关闭此功能
   - **快捷键组合**：选择用于隐藏按钮的快捷键
3. 点击"保存设置"按钮应用更改
4. 设置会自动保存并应用到所有标签页

## 技术实现

- **manifest.json**: 插件配置文件
- **popup.html/popup.js**: 弹出界面及交互逻辑
- **content.js**: 核心滚动功能实现，包括按钮创建和事件处理
- **background.js**: 后台任务和快捷键处理
- **options.html/options.js**: 设置页面及配置管理
- **_locales/**: 多语言翻译文件
- **create-icons.html**: 图标生成工具，可视化创建图标
- **create-icons.js**: 图标生成工具脚本

## 性能优化

- 使用`requestAnimationFrame`实现平滑滚动
- 最小化DOM操作，减少重排重绘
- 事件委托和防抖技术，提高响应速度
- 按需加载功能，减少内存占用
- 优化消息传递机制，提高通信效率
- 使用WeakMap管理状态，防止内存泄漏

## 注意事项

1. **图标文件**：首次安装时需要在`icons`目录创建图标文件
2. **权限**：插件需要访问网页内容的权限，用于添加滚动按钮
3. **兼容性**：在某些特殊网页布局下，按钮位置可能需要调整
4. **快捷键冲突**：如果与其他扩展或系统快捷键冲突，可能需要修改快捷键设置

## 故障排除

- **按钮不显示**：检查插件是否已启用，刷新网页
- **快捷键不工作**：检查是否有快捷键冲突，尝试重新设置
- **颜色显示异常**：确保使用有效的十六进制颜色格式
- **滚动不流畅**：调整滚动速度设置
