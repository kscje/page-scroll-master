快速开始

先了解页面按钮与工具栏 Popup，再按需要调整下方设置。

  1. 使用页面滚动按钮

    网页边缘的上、下箭头可快速滚动到页面顶部或底部。

  2. 从 Chrome 工具栏打开 Popup

    点击 Chrome 工具栏中的扩展图标；若图标未显示，可先在拼图菜单中固定本扩展。

  3. 按当前网站控制功能

    Popup 可分别启停整个扩展和三项高级功能，状态对当前主域名生效。

    扩展 页面进度条 书签 文章大纲

  4. 匿名使用分析由你决定

    匿名使用分析保持关闭，只有你在“建议&关于插件”的“隐私与统计”中主动选择后才会启用。

页面进度条

显示当前页面阅读进度，并可点击快速跳转到指定位置。

无限滚动页面中进度可能随着内容加载而变化。

滚动位置书签

保存当前阅读位置，方便稍后返回并继续阅读。

页面中部会将阅读工具排列在“回到底部”按钮之后，不会夹在滚动方向按钮之间。

智能段落跳转

识别页面标题结构，快速查看目录并跳转到上一段或下一段。

页面中部会将阅读工具排列在“回到底部”按钮之后，不会夹在滚动方向按钮之间。

至少保留一个目录来源，已恢复 H1 + H2。

每批加载目录项必须在 10-50 之间。
